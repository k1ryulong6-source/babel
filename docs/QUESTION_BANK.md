# 单元题库：给每个单元加练习题

> 给负责出题的人或 AI（例如 WorkBuddy 里的 DeepSeek）。从头读完再动手。这项工作只往单元文件里**追加**题目，不改课程讲解、不改应用代码。

## 1. 背景

每个单元有 5 节讲解课 + 1 节单元阅读。课里的练习是固定的，学完一遍就没有新题了。所以每个单元另有一个**单元题库**（单元文件里的 `bank` 字段），应用里这样用它：

- 课程页每个单元下面有「单元题库」：随时刷题，每组 15 题，没做过的先出，上次做错的其次，答错的进错题本。只出已经学完的课时的题。
- 单元测验和回炉也会从题库里抽题，所以题库越大，重测越不容易遇到原题。

**目标：每个单元 60 题（每节讲解课约 12 题）。** 现在 44 个单元的题库都是空的。

**先做哪些单元**：先做学习者正在学的单元和接下来的两三个单元；其次是第二学期（`en.2.*`、`es.2.*`、`ja.2.*`）；最后是第一学期。

## 2. 准备

```bash
git clone https://github.com/k1ryulong6-source/babel.git && cd babel
git checkout -b bank/$(date +%m%d)          # 在新分支上做，不要直接改 main
python3 tools/bank_brief.py es.2.5           # 看这个单元的简报：每课的重点、新词、已有题目示例
python3 tools/bank_brief.py --all bank_inbox/briefs   # 或者一次生成所有单元的简报
```

**出题前一定先读简报**：题目要考这一课的重点和新词，不能超纲，也不能和已有的题重复。需要更多细节时，直接读单元文件 `curriculum/<语言>/<学期>-<单元>.json`。

## 3. 题型和格式

每个单元写一个补丁文件 `bank_inbox/<单元>.json`（例如 `bank_inbox/es.2.5.json`），一次写一个单元：

```json
{"unit": "es.2.5",
 "questions": [
  {"l": 1, "t": "c", "q": "¿Has visto mis gafas? —No, no ___ he visto.", "o": ["las", "los", "les", "la"], "e": "gafas 是阴性复数 → las。"},
  {"l": 1, "t": "f", "q": "¿Dónde compraste esos pantalones? —___ compré en las rebajas.", "a": ["Los"], "e": "pantalones 阳性复数 → los。"},
  {"l": 3, "t": "tr", "zh": "我把钥匙给她了。", "a": ["Se las di.", "Le di las llaves."]},
  {"l": 4, "t": "o", "a": "Voy a cortarlas ahora", "p": ["Voy a", "cortarlas", "ahora"], "zh": "我现在就去把它们切了。"}
 ]}
```

| 字段 | 说明 |
|---|---|
| `l` | 考的是第几课（1–5，简报里写着 `l = 几`）。必填。 |
| `t` | 题型：`c` 选择、`f` 填空、`tr` 中译外、`o` 连词成句、`dict` 听写 |
| `c` 选择题 | `q` 题干（空格用 `___`），`o` 3–4 个选项，**正确答案写在第一个**（合并时会自动打乱），`e` 中文解析（必写，40 字以内，说清为什么） |
| `c` 听力题 | 只用于英语听力单元：`q` 写 “🎧 问题”，`say` 写录音原文（不超过 400 字符），题干里不出现原文 |
| `f` 填空 | `q` 里有一个 `___`；`a` 是所有可接受答案的列表；`e` 解析 |
| `tr` 中译外 | `zh` 中文句子；`a` 写 2–3 种都对的译法 |
| `o` 连词成句 | `a` 正确句子；英语、西语按空格切分，可不写 `p`；日语必须写 `p`（片段数组，拼起来要和 `a` 一字不差）；`zh` 中文提示 |
| `dict` 听写 | `a` 一个句子（英语、西语用；日语判分要求汉字完全一致，少用） |

**每节课 12 题的建议比例：**

| 语言 | 选择 c | 填空 f | 中译外 tr | 连词成句 o | 其他 |
|---|---|---|---|---|---|
| 英语 | 6（托业 Part 5 风格，4 个选项） | 2 | 2 | 1 | 听力单元把 3 道选择换成 🎧 听力题；可加 1 道 dict |
| 西语 | 5（3 个选项） | 3（动词变位、代词） | 2 | 2 | — |
| 日语 | 6（3 个选项，文型和词汇） | 2 | 2 | 2 | — |

## 4. 质量标准

- **考重点**：每课的两个重点（简报里的「重点」）至少各出 4 题；其余考本课新词和搭配。同一个知识点换不同的句子、场景和问法，不要只换一个名词。
- **只有一个正确答案**：干扰项要像样（学习者真会犯的错，如时态、性数、近义词、介词），但不能也说得通。出完自己检查一遍：每个干扰项放进去，句子是不是确实错了？
- **难度不超纲**：只用本单元及以前学过的词和语法。西语 A2 单元不要出虚拟式；英语第二学期按托业 600 的难度。
- **自然地道**：句子是母语者会说的话。英语用职场、出差、客服、购物场景；西语用日常生活、旅行；日语用新闻、社论、商务书面语。
- **解析**用简体中文，说清楚为什么选这个、错的错在哪里，像老师批改，不要只写“正确答案是 A”。
- **禁止**：省略号（“…”“...”，录音工具会跳过这句）、照抄真题（托业、JLPT、DELE 原题和教材题目受版权保护，只能参考题型）、真实名人名字、敏感或冒犯内容、和简报里“已有题目示例”重复。

## 5. 校验、合并、提交

```bash
python3 tools/bank_merge.py bank_inbox/es.2.5.json          # 只校验，逐题列出错误
python3 tools/bank_merge.py --apply bank_inbox/es.2.5.json  # 把没有错误的题追加进单元文件
python3 tools/check_curriculum.py                           # 不能有“错误”
git add curriculum && git commit -m "Question bank: es.2.5 (+60)" && git push -u origin HEAD
```

- 校验脚本会挡掉：格式错误、`l` 超出范围、选项重复、少于 3 个选项、把正确答案没写在第一个、答案或录音里有省略号、外语答案混进中文、和单元里已有的题重复。有错的题改好后重新校验。
- **脚本查不出意思对不对**：合并前请把每个单元的题从头读一遍，尤其检查“干扰项是不是也对”。
- 题库**只追加，不改、不删、不调顺序**：应用按题目在题库里的位置记录做题情况。发现已合并的题有错，告诉维护者处理，不要自己删。
- 不要改 `index.html`、`audio/`、`files.json`、`sw.js`，也不要合并到 `main`：推到自己的分支就行。

## 6. 之后由维护者做

- 抽查题目质量，把有问题的题列出来退回。
- 给听力题、中译外、听写录音（`tools/tts_batch.py`，需要 Google TTS 密钥）。
- 运行 `python3 tools/update_manifest.py`，用户说“合并”后合并到 `main`。
