# 单元简报：es.1.8 A1 收尾

单元目标：现在完成时入门、比较、身体与看病、通讯、职业、A1 总复习
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：现在完成时入门　题库已有 0 题
情境：he estado、has estado、he terminado：西语的现在完成时，和英语 have done 很像。
新词：haber、ya、todavía、examen、pregunta、respuesta、palabra、idioma、problema
搭配 / 表达：¿Has estado en …?、todavía no、¿Qué ha pasado?
- 重点：现在完成时：haber + 过去分词
  - he, has, ha, hemos, habéis, han + 过去分词
  - 过去分词：-ar → -ado（hablado）；-er / -ir → -ido（comido, vivido）
  - 不规则（要背）：hacer → hecho，decir → dicho，ver → visto，escribir → escrito，poner → puesto，volver → vuelto，abrir → abierto
  - 一句话：he / has / ha … + -ado / -ido；hecho, dicho, visto, escrito, puesto, vuelto, abierto 单独记。
  - 常错：Tengo comido. → He comido.（助动词是 haber）
  - 常错：He hacido. → He hecho.（不规则分词）
- 重点：什么时候用：今天 / 已经 / 从未；ya 和 todavía no
  - 说还没结束的时间段里发生的事：hoy, esta semana, este año —— Hoy he trabajado mucho.
  - 说经历：¿Has estado en Barcelona? Nunca he visto la nieve.
  - ya 已经：Ya he comido.　todavía no 还没有：Todavía no he terminado.
  - 一句话：今天 / 这周 / 经历 → 现在完成时；ya 已经，todavía no 还没。
  - 常错：— ¿Has terminado? — No todavía. → Todavía no.（语序）
  - 常错：Nunca he no visto. → Nunca he visto.（nunca 在前不再加 no）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] ¿Has estado en Barcelona?

## 第 2 课（l = 2）：比较：más / menos que　题库已有 0 题
情境：más … que、mejor、lo más importante：比较的说法。
新词：más、mayor、bueno、malo、rápido、importante、interesante、simpático
搭配 / 表达：mucho mejor、cada vez más、lo más importante
- 重点：más / menos … que；tan … como
  - más + 形容词 + que：比……更…… —— Madrid es más grande que Toledo.
  - menos + 形容词 + que：比……不…… —— El tren es menos caro que el avión.
  - tan + 形容词 + como：和……一样 —— Ana es tan alta como su madre.
  - 最高级：el / la / los / las + más + 形容词 + de：Es la ciudad más bonita de España.
  - 一句话：más / menos … que；tan … como；el más … de。
  - 常错：tan alta que su madre → tan alta como su madre（）
  - 常错：la más bonita en España → la más bonita de España（范围用 de）
- 重点：不规则：mejor、peor、mayor、menor
  - bueno → mejor（更好）；malo → peor（更坏）
  - 年龄：mayor（年纪更大）/ menor（年纪更小）—— Mi hermana es mayor que yo.
  - 不说 más bueno、más malo（指品质时）；“哥哥 / 姐姐”常说 hermano mayor / hermana mayor
  - 一句话：mejor / peor / mayor / menor。
  - 常错：más bueno → mejor（）
  - 常错：Mi hermana es más grande que yo.（年龄） → Mi hermana es mayor que yo.（）

## 第 3 课（l = 3）：身体与看病　题库已有 0 题
情境：me duele la cabeza、me duelen los ojos：“疼”的说法和 gustar 一模一样。
新词：cabeza、estómago、mano、pie、boca、doler、dolor、medicina、salud、espalda
搭配 / 表达：¿Qué te duele?、¡Que te mejores!、ir al médico
- 重点：doler 像 gustar：疼的部位是主语
  - me / te / le … + duele + 单数：Me duele la cabeza.
  - me / te / le … + duelen + 复数：Me duelen los pies.
  - 身体部位前用定冠词，不用物主形容词：Me duele la mano（不说 mi mano）
  - 也可以说 tener dolor de + 部位：Tengo dolor de estómago.
  - 一句话：me duele + 单数 / me duelen + 复数；部位前用 el / la。
  - 常错：Me duele mi mano. → Me duele la mano.（部位用定冠词）
  - 常错：Me duele los ojos. → Me duelen los ojos.（复数用 duelen）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 对生病的朋友说？　选项：¡Buen viaje! / ¡Que te mejores! / ¡Feliz cumpleaños! / ¡Buen provecho!　答案：¡Que te mejores!
  - [f] ¿Qué te ___? — Me duele la espalda.　答案：duele
  - [o] Tengo que ir al médico.

## 第 4 课（l = 4）：手机、消息与电话　题库已有 0 题
情境：lo tengo、te mando：西语的宾语代词放在动词前面。
新词：móvil、mensaje、ordenador、foto、papel、televisión、radio、reloj
搭配 / 表达：Te llamo luego.、¿Me das tu número?、No hay cobertura.
- 重点：宾格代词 lo / la / los / las 放在变位动词前
  - 代替上文提到的东西或人（直接宾语）：
  - 阳性单数 lo，阴性单数 la，阳性复数 los，阴性复数 las
  - 位置：放在变位动词前：¿Tienes el móvil? — Sí, lo tengo.
  - 和原形、命令式连用时接在后面、写成一个词：Voy a llamarte. ¡Cómelo!
  - 一句话：lo / la / los / las + 变位动词；原形后面可以连写：llamarte。
  - 常错：Tengo lo. → Lo tengo.（放动词前）
  - 常错：¿Ves las fotos? — Sí, los veo. → Sí, las veo.（fotos 阴性）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 西班牙人接电话常说？　选项：¿Diga? / ¿Qué? / ¿Hola qué? / ¿Bueno sí?　答案：¿Diga?
  - [o] Te llamo luego.

## 第 5 课（l = 5）：工作与职业 · A1 总复习　题库已有 0 题
情境：这一课把整个 A1 串起来：ser / estar / hay，三类变位，gustar，ir a。
新词：trabajo、oficina、jefe、ingeniero、enfermero、abogado、cocinero、dependiente、policía
搭配 / 表达：¿Dónde trabajas?、Trabajo como …、¡Mucho ánimo!
- 重点：A1 总复习：选动词的四个问题
  - ① 说身份、职业、国籍、性格？→ ser：Soy ingeniera. Es simpático.
  - ② 说在哪儿、此刻的状态？→ estar：Está en la oficina. Estoy cansado.
  - ③ 说某处有什么？→ hay：Hay un banco cerca.
  - ④ 说喜欢、疼？→ gustar / doler，东西是主语：Me gusta mi trabajo. Me duelen los pies.
  - 一句话：ser 身份 / estar 位置状态 / hay 有 / gustar 东西作主语。
  - 常错：Mi madre está abogada. → Mi madre es abogada.（职业用 ser）
  - 常错：Mi jefe es en la oficina. → Mi jefe está en la oficina.（位置用 estar）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] ¿A qué te ___? — Soy cocinero.　答案：dedicas
  - [o] Me gusta mucho mi trabajo.
  - [tr] 你是做什么工作的？ → ¿A qué te dedicas?
