# 单元简报：es.1.2 你好，我是……

单元目标：问候、ser、主语代词、名词的性、冠词、数字 0–10：能做简单的自我介绍
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：自我介绍：llamarse　题库已有 0 题
情境：先听一遍。这一课学会：说自己叫什么、问别人叫什么，以及什么时候用「你」、什么时候用「您」。
新词：nombre、señor、amigo、estudiante、profesor、compañero、de nada、por favor、vale
搭配 / 表达：¿Cómo te llamas?、Me llamo …、¿Y usted?
- 重点：“我叫……”：me llamo / te llamas / se llama
  - 西语不说“我的名字是”，而是说 Me llamo + 名字。
  - me llamo 我叫 · te llamas 你叫 · se llama 他 / 她 / 您叫
  - 问名字：¿Cómo te llamas?（对熟人）/ ¿Cómo se llama usted?（对长辈、陌生人）
  - 一句话：Me llamo + 名字；问名字用 ¿Cómo te llamas?
  - 常错：¿Qué te llamas? → ¿Cómo te llamas?（问名字用 cómo）
  - 常错：Yo llamo Ana. → Me llamo Ana.（少了 me（自己））
- 重点：“你”和“您”：tú 与 usted
  - 西语的“你”分两种：
  - tú：朋友、同学、家人、小孩 —— 动词用“你”的形式：te llamas, eres
  - usted：长辈、陌生人、顾客、上司 —— 动词用第三人称，和“他 / 她”一样：se llama, es
  - 一句话：usted = 您，动词和“他 / 她”一样。
  - 常错：¿Cómo te llama usted? → ¿Cómo se llama usted?（usted 配第三人称 se llama）
  - 常错：Usted eres profesor. → Usted es profesor.（usted 配 es）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] Un café, por ___.　答案：favor
  - [c] 女生说“很高兴认识你”：　选项：Encantado. / Encantada. / Encantados. / Encanta.　答案：Encantada.
  - [tr] 你好，我叫安娜。你叫什么名字？ → Hola, me llamo Ana. ¿Cómo te llamas?

## 第 2 课（l = 2）：主语代词与 ser　题库已有 0 题
情境：这一课学会：我、你、他……这些代词，以及最重要的动词 ser（是）。
新词：yo、tú、él、ella、usted、nosotros、ellos、español、chino、japonés
搭配 / 表达：¿De dónde eres?、Soy de …、¿A qué te dedicas?
- 重点：ser（是）的变位 —— 必须背熟
  - ser 是西语最常用、也最不规则的动词，六个形式要整个背下来：
  - yo soy · tú eres · él / ella / usted es
  - nosotros somos · vosotros sois · ellos / ellas / ustedes son
  - 一句话：soy, eres, es, somos, sois, son —— 每天念三遍。
  - 常错：Yo es estudiante. → Yo soy estudiante.（yo → soy）
  - 常错：Nosotros son amigos. → Nosotros somos amigos.（nosotros → somos）
- 重点：用 ser 说身份：职业不加冠词，国籍跟着性别变
  - ser de + 地方 = 来自……：Es de Pekín.
  - ser + 职业：职业前不加冠词：Soy profesor.（不说 Soy un profesor）
  - 国籍是形容词，要和人的性别、单复数一致，而且小写：chino / china / chinos / chinas；japonés / japonesa；español / española
  - 一句话：职业不加冠词；国籍小写、跟着人变阴阳单复。
  - 常错：Soy un estudiante. → Soy estudiante.（职业前不加冠词）
  - 常错：Ella es chino. → Ella es china.（女性用 china）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] Usted ___ profesora, ¿no?　选项：eres / es / soy / son　答案：es
  - [tr] 你是哪里人？ → ¿De dónde eres?
  - [o] Nosotros somos de China.

## 第 3 课（l = 3）：名词的性与数　题库已有 0 题
情境：注意 un libro 和 una foto：为什么一个用 un、一个用 una？这一课就讲这个。
新词：hombre、mujer、niño、chico、persona、libro、mesa、coche、ciudad、gente
搭配 / 表达：¿Qué es esto?、Es un/una …、Mucha gente
- 重点：每个名词都有“性别”
  - 西语名词分阳性和阴性，和真实性别无关：libro（书）是阳性，mesa（桌子）是阴性。
  - 规律：-o 结尾多为阳性；-a 结尾多为阴性；-ción / -sión / -dad / -tad 结尾一定是阴性；-or 多为阳性。
  - 常见例外单独记：el día, el mapa, el problema, el idioma（-a 却是阳性）；la mano, la foto, la moto, la radio（-o 却是阴性）。
  - 一句话：背名词连冠词：el día，la mano，la ciudad。
  - 常错：el ciudad → la ciudad（-dad 一定是阴性）
  - 常错：la problema → el problema（-ma 结尾的希腊来源词多为阳性）
- 重点：变复数；gente 是单数
  - 元音结尾 + s：libro → libros，mesa → mesas。
  - 辅音结尾 + es：ciudad → ciudades，profesor → profesores。
  - -z 结尾变 -ces：lápiz → lápices。
  - 冠词、形容词也一起变复数：los chicos altos, las casas nuevas。
  - 一句话：元音 +s，辅音 +es，-z 变 -ces；gente 单数、persona 阴性。
  - 常错：La gente son amables. → La gente es amable.（gente 是单数）
  - 常错：dos ciudads → dos ciudades（辅音结尾加 -es）
已有题目示例（不要重复，也不要只换几个词）：
  - [tr] 这是我朋友的书。 → Es el libro de mi amigo.
  - [o] Es un libro de mi amigo.

## 第 4 课（l = 4）：冠词　题库已有 0 题
情境：西语名词前几乎总带冠词。注意 la calle、un hotel、al lado del banco。
新词：el、la、los、las、un、una、cosa、país、calle
搭配 / 表达：Voy al …、Es del …、Una cosa más.
- 重点：el / la 还是 un / una？
  - 定冠词 el / la / los / las：说双方都知道是哪个的东西，相当于“这个、那个”。
  - 不定冠词 un / una / unos / unas：第一次提到、对方不知道是哪个，相当于“一个、一些”。
  - 冠词和名词同性同数。
  - 一句话：认识的用 el / la，第一次说用 un / una；泛指一类也用 el / la；hay 后面用 un / una。
  - 常错：Me gusta café. → Me gusta el café.（泛指一类要加定冠词）
  - 常错：Hay el hotel aquí. → Hay un hotel aquí.（hay（有）后面用不定冠词）
- 重点：缩合：a + el = al，de + el = del
  - a + el → al：Voy al banco.（不说 a el banco）
  - de + el → del：Es el coche del profesor.
  - 只有 el 会缩合；a la、de la、a los、de las 都不变。
  - 专有名词里的 El 不缩合：Voy a El Salvador.
  - 一句话：a / de 碰到 el 才合并：al、del。
  - 常错：Voy a el banco. → Voy al banco.（a + el 必须缩合）
  - 常错：el libro de el profesor → el libro del profesor（de + el 必须缩合）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] ___ países（定冠词）　答案：los
  - [c] Tengo ___ amiga en Madrid.　选项：un / una / el / unos　答案：una
  - [o] La calle es muy bonita.

## 第 5 课（l = 5）：数字 0–10　题库已有 0 题
新词：uno、dos、tres、cuatro、cinco、seis、siete、ocho、nueve、diez
搭配 / 表达：¿Cuántos años tienes?、Tengo … años.、¿Cuál es tu número de teléfono?
- 重点：说年龄用 tener（有），不用 ser
  - 西语说年龄：tener + 数字 + años：Tengo diez años = “我有十年” = 我十岁。
  - tener 的变位：tengo · tienes · tiene · tenemos · tenéis · tienen
  - 问年龄：¿Cuántos años tienes?（你几岁？）/ ¿Cuántos años tiene usted?
  - 一句话：年龄、饿、冷、有道理 —— 都用 tener。
  - 常错：Soy diez años. → Tengo diez años.（年龄用 tener）
  - 常错：Tengo diez. → Tengo diez años.（完整说法带 años）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] cinco + tres = ___　选项：seis / siete / ocho / nueve　答案：ocho
  - [c] nueve − cuatro = ___　选项：cinco / cuatro / seis / tres　答案：cinco
  - [c] 听到的数字是？　选项：seis / siete / diez / dos　答案：siete
