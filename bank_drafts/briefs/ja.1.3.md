## 第 1 课（l = 1）：気持ちの動詞　题库已有 0 题
情境：先读一遍。这一单元是“心”的词：中文里一个“烦”“急”“不好意思”，日语分成好几个词。
新词：戸惑う、苛立つ、焦れる、憤る、妬む、拗ねる、萎える、案じる、気遣う、労る、宥める、詫びる、恥じらう、思い詰める、感極まる
搭配 / 表达：胸を撫で下ろす、気が気でない、肝を冷やす、気が引ける
- 重点：〜てやまない
  - 意思：衷心……；……不已
  - 接续：動詞て形＋やまない（やみません）
  - 一句话：願う・祈る・期待する・愛する＋てやまない：衷心、一直。
  - 常错：毎日走ってやまない。 → 毎日走り続けている。（只接愿望、爱慕类动词）
- 重点：〜を禁じ得ない
  - 意思：不禁……；禁不住……
  - 接续：感情名詞（怒り・同情・涙・驚き）＋を禁じ得ない
  - 一句话：感情名詞＋を禁じ得ない（书面）。
  - 常错：泣くを禁じ得なかった。 → 涙を禁じ得なかった。／泣かずにはいられなかった。（只接名词）

  - [c] 泣いている子を優しく___。　选项：宥めた / 憤った / 妬んだ / 焦れた　答案：宥めた
  - [c] 優勝が決まり、彼女は___涙を流した。　选项：感極まって / 思い詰めて / 拗ねて / 萎えて　答案：感極まって

## 第 2 课（l = 2）：態度と性格　题库已有 0 题
情境：先读一遍。这一单元是“心”的词：中文里一个“烦”“急”“不好意思”，日语分成好几个词。
新词：図々しい、厚かましい、おこがましい、白々しい、よそよそしい、馴れ馴れしい、ふてぶてしい、潔い、奥ゆかしい、慎ましい、気難しい、抜け目ない、甲斐甲斐しい、逞しい、健気
搭配 / 表达：八方美人、猫をかぶる、鼻にかける、腰が低い
- 重点：〜きらいがある
  - 意思：有……的（不好）倾向
  - 接续：名詞＋の・動詞辞書形・ない形＋きらいがある
  - 一句话：坏毛病＋きらいがある（批评、书面）。
  - 常错：彼女は人に親切にするきらいがある。 → 彼女は人に親切だ。（正面的事不用）
  - 常错：物価が上がるきらいがある。 → 物価が上昇する傾向にある。（统计趋势用「傾向」）
- 重点：〜といったらない
  - 意思：……得不得了；……得无法形容
  - 接续：名詞・い形辞書形＋といったらない（ったらない）
  - 一句话：Ａ（の程度）といったらない：Ａ得没法形容。
  - 常错：寒いといったらある。 → 寒いといったらない。（固定否定形）

## 第 3 课（l = 3）：人づきあい　题库已有 0 题
情境：先读一遍。这一单元是“心”的词：中文里一个“烦”“急”“不好意思”，日语分成好几个词。
新词：迎合、追従、贔屓、忖度、懐柔、庇護、中傷、陰口、気心、波風、人望、面子、世間体、相槌、愛想
搭配 / 表达：気が置けない、馬が合う、顔を立てる、角が立つ
- 重点：〜手前
  - 意思：当着……的面；既然……（顾及面子）
  - 接续：名詞＋の・動詞辞書形・た形＋手前
  - 一句话：人の手前／〜た手前 + 不能做 / 不得不做（顾及面子）。
  - 常错：お腹が空いた手前、ご飯を食べた。 → お腹が空いたので、ご飯を食べた。（没有面子、体面的因素）
- 重点：〜をいいことに
  - 意思：趁着……；以……为可乘之机
  - 接续：名詞・普通形＋の＋をいいことに
  - 一句话：有利条件をいいことに + 钻空子、做坏事（贬义）。
  - 常错：温かいのをいいことに、早く食べてください。 → 温かいうちに食べてください。（中性的“趁”不用）

## 第 4 课（l = 4）：心の形容詞　题库已有 0 题
情境：先读一遍。这一单元是“心”的词：中文里一个“烦”“急”“不好意思”，日语分成好几个词。
新词：やるせない、居たたまれない、もどかしい、歯痒い、心許ない、後ろめたい、心苦しい、気恥ずかしい、煩わしい、物足りない、味気ない、素っ気ない、忍びない、恨めしい、未練がましい
搭配 / 表达：後ろ髪を引かれる、身につまされる、胸が痛む、気がとがめる
- 重点：〜に堪えない
  - 意思：不胜……（感情）；不堪（看、听）
  - 接续：感情名詞＋に堪えない；動詞辞書形（見る・聞く・読む）＋に堪えない
  - 两个意思，前面接的词不同：
  - ① 感情名詞＋に堪えない：不胜……、非常……（郑重）—— 感謝の念に堪えません・感激に堪えない・遺憾に堪えない
  - ② 見る・聞く・読む＋に堪えない：不堪入目 / 入耳（太差了，没法看、没法听）
  - 一句话：感謝の念に堪えません（郑重）；見るに堪えない（不堪入目）。
  - 常错：感謝に堪えます。 → 感謝に堪えません。／感謝の念に堪えません。（否定形）
  - 常错：食べるに堪えない（想说“不想吃”） → とても食べられない（只接見る・聞く・読む）
- 重点：〜ずにはおかない
  - 意思：必然会……；非……不可
  - 接续：動詞ない形＋ずにはおかない（する→せずにはおかない）
  - ① 主语是事物：必然会引起……（不以人的意志为转移）—— 人を感動させずにはおかない
  - ② 主语是说话人：非……不可（决心）—— 真相を暴かずにはおかない
  - する → せずにはおかない
  - 一句话：事物＋ずにはおかない：必然引起；忍不住是ずにはいられない。
  - 常错：おかしくて、笑わずにはおかなかった。 → おかしくて、笑わずにはいられなかった。（控制不住的情绪用「いられない」）

  - [c] 思い出の品を捨てるのは___。　选项：忍びない / 煩わしい / 心許ない / 白々しい　答案：忍びない

## 第 5 课（l = 5）：言動の動詞　题库已有 0 题
情境：先读一遍。这一单元是“心”的词：中文里一个“烦”“急”“不好意思”，日语分成好几个词。
新词：諭す、戒める、促す、仰ぐ、委ねる、庇う、欺く、偽る、煽る、仕向ける、見下す、侮る、見くびる、罵る、晒す
搭配 / 表达：釘を刺す、口を挟む、耳を傾ける、歯に衣着せぬ
- 重点：〜とばかりに
  - 意思：（神态）简直像在说……
  - 接续：引用・普通形・命令形＋とばかりに
  - 一句话：「……」とばかりに：描写他人神态；ここぞとばかりに。
  - 常错：私は「助けて」とばかりに叫んだ。 → 私は「助けて」と叫んだ。（不用于自己）
- 重点：〜んばかり
  - 意思：几乎要……；简直要……
  - 接续：動詞ない形＋んばかり（に・の・だ）（する→せんばかり）
  - 一句话：ない形＋んばかり：几乎要……（实际没发生）。
  - 常错：泣き出すばかりの顔 → 泣き出さんばかりの顔（ない形＋ん）
  - 常错：溢れんばかりに泣いた。（真的流出来了） → 涙があふれた。（实际发生了就不用）
