# 单元简报：es.1.1 发音与拼读复习

单元目标：元音、音节、重音规则、r/rr、c/z/g/j/ll/ñ、连读与语调
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：五个元音与音节　题库已有 0 题
情境：西语是“写什么读什么”的语言，只要五个元音读准，大部分单词看到就能读。
新词：hola、adiós、gracias、sí、no、casa、agua、día、noche
搭配 / 表达：¡Hola!、Muchas gracias.、Adiós.
- 重点：五个元音：短、纯、不滑动
  - 西语只有 5 个元音 a e i o u，在任何位置都读同一个音：
  - a ≈ “啊”　e ≈ “诶”（嘴形不动）　i ≈ “衣”　o ≈ “喔”（嘴形不动）　u ≈ “乌”
  - 每个元音短促、清楚、口型从头到尾不变；不重读的元音也照样读清楚，不弱化。
  - 一句话：五个元音短、纯、不滑，不重读也读清楚。
  - 常错：no 读成 /nəʊ/（像英语 know） → no：干脆的 /no/（o 不滑）
  - 常错：noche 的 e 读成含糊的 /ə/ → noche：e 读清楚（不弱化）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] agua 分成几个音节？　选项：1 / 2 / 3 / 4　答案：2
  - [c] día 分成几个音节？　选项：1 / 2 / 3　答案：2
  - [c] leer 怎么分音节？　选项：leer / le-er / l-eer / lee-r　答案：le-er

## 第 2 课（l = 2）：重音规则与重音符号　题库已有 0 题
情境：西语重音有规则：看拼写就知道重音在哪；不符合规则的，就写重音符号。
新词：café、teléfono、árbol、médico、música、película、fácil、difícil、número
搭配 / 表达：¿Cómo se dice … en español?、¿Qué significa …?、Otra vez, por favor.
- 重点：重音规则：两条规则 + 重音符号
  - 规则 1：以元音、n、s 结尾 → 重音在倒数第二个音节：CA-sa，HA-blan，LU-nes
  - 规则 2：以 n、s 以外的辅音结尾 → 重音在最后一个音节：ha-BLAR，ciu-DAD，es-pa-ÑOL
  - 不符合规则的词，必须写重音符号：ca-FÉ，ÁR-bol，te-LÉ-fo-no，MÚ-si-ca
  - 一句话：元音 / n / s 结尾 → 倒数第二；其他辅音结尾 → 最后；有符号 → 听符号的。
  - 常错：TE-le-fo-no → te-LÉ-fo-no（看重音符号）
  - 常错：ha-BLAN → HA-blan（n 结尾，倒数第二音节）
- 重点：重音符号区分同形词
  - 有些词只靠重音符号区分意思：
  - sí 是 / si 如果　tú 你 / tu 你的　él 他 / el 定冠词
  - qué, cómo, dónde, cuándo（疑问词）/ que, como, donde, cuando（连词）
  - 一句话：疑问词一律带符号；sí / si、tú / tu、él / el 靠符号区分。
  - 常错：¿Como estas? → ¿Cómo estás?（疑问词和 estás 都要符号）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Otra vez, por favor.
  - [tr] 这是什么意思？ → ¿Qué significa esto?

## 第 3 课（l = 3）：r 与 rr　题库已有 0 题
情境：perro 和 pero、arroz 和 caro：r 和 rr 是两个不同的音，读错就是另一个词。
新词：arroz、perro、pero、río、rojo、correr、ropa、carta、tren
搭配 / 表达：¡Qué rico!、Un momento.、No pasa nada.
- 重点：r（单击）和 rr（颤音）：pero 不是 perro
  - 单击 r（两个元音之间、辅音后的单个 r）：舌尖向上轻弹一下上齿龈，只碰一次 —— pero，cara，para。
  - 颤音 rr（写成 rr、词首的 r、n / l / s 后的 r）：舌尖放松，被气流吹得连续颤动 3–5 次 —— perro，rojo，río，honra。
  - 两者区别就在颤几下：一下 vs 好几下。
  - 一句话：r 弹一下，rr 和词首 r 颤好几下；颤不出来先用清楚的单击音，别卷舌。
  - 常错：perro 读成 pero → perro：舌尖连续颤（意思变成“但是”）
  - 常错：rojo 用英语卷舌 r → rojo：词首 r 颤音（舌头不要往后卷）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] pero 的意思是？　选项：狗 / 但是 / 贵 / 车　答案：但是
  - [f] No pasa ___. (没关系)　答案：nada
  - [o] El perro come arroz.

## 第 4 课（l = 4）：c/z、g/j、h、ll/y、ñ、qu/gu　题库已有 0 题
情境：jamón、mañana、queso、cerveza、llave：几个字母的读法和英语、拼音都不一样。
新词：zumo、jamón、llave、mañana、queso、cerveza、ojo、cuchara、cuchillo
搭配 / 表达：¿Qué hora es?、Hasta mañana.、¡Qué bien!
- 重点：c / z、g / j、qu / gu：看后面的元音
  - c：在 a o u 前读 /k/（casa, como）；在 e i 前读咬舌的 /θ/（西班牙）或 /s/（拉美）：cena, cine
  - z 永远读 /θ/ 或 /s/：zumo, cerveza
  - g：在 a o u 前读 /g/（gato）；在 e i 前读喉音 /x/，和 j 一样：gente, girar
  - j 永远读 /x/：jamón, ojo —— 像用力哈气的“赫”
  - 要在 e i 前读 /k/、/g/，就写 que, qui, gue, gui（u 不读）：queso, guitarra
  - 一句话：c、g 在 e、i 前变软；j 永远喉音；que / qui / gue / gui 的 u 不读。
  - 常错：jamón 读成“佳萌” → jamón：j 是喉音“哈”（）
  - 常错：queso 读成“去索” → queso /ˈkeso/（u 不读）
- 重点：h 不读；ll / y；ñ
  - h 永远不发音：hola, hijo, hora
  - ll 和 y（在元音前）多数地区读同一个音，像“呀”的开头 /ʝ/：llave, calle, yo；阿根廷读得像“沙”
  - ñ 像“妞”的声母 /ɲ/：mañana, España, niño
  - 一句话：h 不读，ll ≈ y，ñ ≈ 妞。
  - 常错：hola 读成 /ˈhola/ → hola /ˈola/（h 不读）
  - 常错：calle 读成“卡勒” → calle /ˈkaʝe/（ll 读 /ʝ/）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] ¿Qué ___ es? — Son las dos.　答案：hora
  - [o] Hasta mañana.
  - [tr] 几点了？ → ¿Qué hora es?

## 第 5 课（l = 5）：连读与语调　题库已有 0 题
情境：mis amigos 读成 mi-sa-mi-gos：西语句子是一串一串连起来说的。
新词：¿qué tal?、buenos días、buenas tardes、buenas noches、hasta luego、mucho gusto、encantado、bienvenido、perdón、lo siento
搭配 / 表达：¿Y tú?、Muy bien.、Encantado / Encantada.
- 重点：连读：词和词之间不断开
  - 前一词的辅音 + 后一词的元音 → 连在一起：los_amigos → lo-sa-mi-gos，mis_hijos → mi-si-jos（h 不读）
  - 前一词的元音 + 后一词的元音 → 合成一个音节：la_amiga → la-mi-ga，¿qué_es? → quees
  - 整个意群（一口气说的一串词）像一个长单词。
  - 一句话：辅音 + 元音、元音 + 元音：一律连起来。
  - 常错：los / amigos 分开读 → lo-sa-mi-gos（）
- 重点：语调和倒写的问号、叹号
  - 陈述句：句末下降。
  - 一般疑问句（回答是 / 否）：句末上扬 —— ¿Tienes hambre? ↗
  - 特殊疑问句（有疑问词）：句末一般下降 —— ¿Dónde vives? ↘
  - 书写：问句和感叹句开头也要写倒置的符号：¿…?　¡…!
  - 一句话：是非问句上扬，疑问词问句下降；开头写 ¿ ¡。
  - 常错：Tienes hambre?（只写一个问号） → ¿Tienes hambre?（开头要写 ¿）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 女性说“很高兴认识你”用？　选项：Encantado / Encantada　答案：Encantada
  - [c] 早上见面打招呼用？　选项：Buenas noches / Buenos días / Buenas tardes / Hasta luego　答案：Buenos días
  - [f] Estoy bien, ¿y ___?　答案：tú
