## 第 1 课（l = 1）：顔と目　题库已有 0 题
情境：先读一遍。这一单元的惯用句都和身体有关，单看字面常常会误解。
新词：敢えて、却って、強いて、努めて、程なく、些か、自ずと、飽くまで、元より、とうに、優に、長らく、夢にも、日増しに、仮にも
搭配 / 表达：顔が広い、顔に泥を塗る、目に余る、目を光らせる、目から鱗が落ちる、大目に見る
- 重点：〜ともなると
  - 意思：一旦到了……（地位、阶段）；要是……的话
  - 接续：名詞・動詞辞書形＋ともなると（ともなれば）
  - 前面是较高的地位、年龄、特殊的阶段或时期：社長・大学生・十二月・週末
  - 后面是到了那个阶段理所当然会出现的情况。
  - 一句话：高的地位 / 特殊阶段＋ともなると + 理所当然的变化。
  - 常错：昨日ともなると雨が降った。 → 昨日は雨が降った。（前面要是“阶段”，不能是一个普通时间点）
- 重点：〜にもまして
  - 意思：比……更；较……尤甚
  - 接续：名詞＋にもまして、何にもまして、以前にもまして
  - 比……更……（在本来已经很高的基准上更进一步）
  - 常用：以前にもまして・例年にもまして・何にもまして（比什么都）
  - 一句话：（本已很高的）Ａにもまして更……；何にもまして。
  - 常错：昨日にもまして今日は涼しい。（昨日并不热） → 昨日より今日は涼しい。（前项本身要已经程度很高）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 親切のつもりが、___迷惑をかけてしまった。　选项：却って / 努めて / 優に / 仮にも　答案：却って
  - [c] 会場には___千人を超える人が集まった。　选项：優に / 強いて / 敢えて / 夢にも　答案：優に
  - [c] こんな結果になるとは___思わなかった。　选项：夢にも / 飽くまで / 自ずと / 元より　答案：夢にも

## 第 2 课（l = 2）：口と耳と鼻　题库已有 0 题
情境：先读一遍。这一单元的惯用句都和身体有关，单看字面常常会误解。
新词：甚だしい、著しい、目覚ましい、目まぐるしい、際どい、由々しい、嘆かわしい、紛らわしい、痛ましい、生々しい、華々しい、根強い、根深い、程遠い、慌ただしい
搭配 / 表达：口が堅い、口車に乗る、耳が痛い、小耳に挟む、鼻が高い、鼻につく
- 重点：〜や否や
  - 意思：刚一……就……
  - 接续：動詞辞書形＋や否や（や）
  - 動詞辞書形＋や否や（也可只说「や」）：刚一……就……
  - 前后几乎同时发生，后项常是意外、迅速的反应。
  - 一句话：辞書形＋や否や + 迅速的反应（书面，描写他人）。
  - 常错：駅に着くや否や、連絡してください。 → 駅に着いたらすぐ連絡してください。（后项不能是请求）
- 重点：〜ともなく
  - 意思：无意中……；不经意地……；不知（从哪里、何时）
  - 接续：動詞辞書形＋ともなく（ともなしに）；疑問詞（どこ・誰・いつ）＋（から）ともなく
  - ① 動詞辞書形＋ともなく：无意中、不经意地做（前后多是同类动词）：見るともなく見る・聞くともなく聞く
  - ② 疑問詞（＋助詞）＋ともなく：不知……：どこからともなく（不知从哪儿）、誰からともなく（不知是谁先）
  - 一句话：見るともなく見る（无意中）；どこからともなく（不知从哪儿）。
  - 常错：どこともなく音がした。 → どこからともなく音がした。（要加助词から）

  - [c] 完成には___。　选项：程遠い / 根強い / 華々しい / 際どい　答案：程遠い
  - [c] この二つの名前は___。　选项：紛らわしい / 目覚ましい / 根深い / 由々しい　答案：紛らわしい

## 第 3 课（l = 3）：手の慣用句　题库已有 0 题
情境：先读一遍。这一单元的惯用句都和身体有关，单看字面常常会误解。
新词：手厚い、手堅い、手強い、手痛い、手厳しい、手ぬるい、手際、手綱、手狭、手薄、不手際、小手先、手間取る、手控える、手こずる
搭配 / 表达：手を焼く、手に負えない、手のひらを返す、手塩に掛ける、手が込む、手を引く
- 重点：〜をものともせず
  - 意思：不把……放在眼里；不畏……
  - 接续：名詞＋をものともせず（に）
  - 名詞＋をものともせず（に）：不把（困难、危险）放在眼里，勇敢地做
  - 前面多是：困難・危険・嵐・けが・逆境・反対
  - 一句话：困难 / 危险をものともせず（勇敢，褒义）。
  - 常错：私は困難をものともせず頑張った。 → 私は困難に負けずに頑張った。（不用于自夸）
- 重点：〜をよそに
  - 意思：不顾……；无视……
  - 接续：名詞＋をよそに
  - 名詞＋をよそに：不顾、无视（别人的担心、反对、期待）
  - 前面多是：心配・反対・期待・批判・騒ぎ
  - 一句话：人の心配・反対・期待をよそに（无视，多贬）。
  - 常错：嵐をよそに山に登った。（想表达勇敢） → 嵐をものともせず山に登った。（客观困难用をものともせず）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 今度の相手はかなり___。　选项：手強い / 手狭 / 手薄 / 小手先　答案：手強い
  - [c] 事務所が___になってきた。　选项：手狭 / 手厚く / 手痛く / 手綱　答案：手狭
  - [c] 警備が___な時間帯を狙われた。　选项：手薄 / 手堅 / 手際 / 手厳し　答案：手薄

## 第 4 课（l = 4）：足・腰・腹・胸　题库已有 0 题
情境：先读一遍。这一单元的惯用句都和身体有关，单看字面常常会误解。
新词：携わる、培う、募る、翻す、阻む、危ぶむ、覆す、損なう、催す、講じる、強いる、揺るがす、据える、潜む、営む
搭配 / 表达：足を洗う、腰を据える、腹を括る、胸を張る、腰が重い、足が遠のく
- 重点：〜はおろか
  - 意思：别说……就连……也
  - 接续：名詞＋はおろか、〜も・さえ・まで
  - Ａはおろか、Ｂも／さえ／まで：别说Ａ了，就连Ｂ也……
  - Ａ是程度较高（更难）的，Ｂ是程度较低（更容易）的，后项多为否定或负面。
  - 一句话：難しいＡはおろか、易しいＢも + 否定 / 负面。
  - 常错：彼は英語はおろか、日本語も話せる。（正面） → 彼は英語だけでなく、日本語も話せる。（正面的事不用）
  - 常错：漢字はおろか、ひらがなも覚えなさい。 → 漢字はもちろん、ひらがなも覚えなさい。（命令、请求句用「はもちろん」）
- 重点：〜のみならず
  - 意思：不仅……而且……
  - 接续：名詞・普通形＋のみならず（〜も）
  - Ａのみならず（Ｂも）：不仅Ａ，而且Ｂ（「だけでなく」的书面形）
  - 放在句首「のみならず、……」＝而且、不仅如此
  - 一句话：Ａのみならず、Ｂも（书面的“不仅……而且”）。
  - 常错：ケーキのみならず、クッキーも食べたよ！（和朋友聊天） → ケーキだけじゃなくて、クッキーも食べたよ！（のみならず 是书面语，聊天用「だけじゃなくて」）

  - [c] 健康を___ような働き方はやめよう。　选项：損なう / 据える / 阻む / 強いる　答案：損なう

## 第 5 课（l = 5）：ことわざ　题库已有 0 题
情境：先读一遍。这一单元的惯用句都和身体有关，单看字面常常会误解。
新词：際立つ、心得る、揺らぐ、報われる、隔てる、彩る、装う、施す、逃れる、兼ねる、見受ける、踏ん張る、開き直る、似通う、帯びる
搭配 / 表达：急がば回れ、石の上にも三年、猿も木から落ちる、灯台下暗し、情けは人の為ならず、背に腹は替えられぬ
- 重点：〜ばこそ
  - 意思：正因为……才……
  - 接续：動詞・形容詞仮定形＋ばこそ、〜のだ
  - 仮定形＋ばこそ（〜のだ）：正因为……才……
  - 强调唯一的、积极的原因，常用来解释别人可能误解的行为：（不是坏意，）正是因为爱你才骂你。
  - 一句话：仮定形＋ばこそ：正因为（积极的原因）……才。
  - 常错：雨が降ればこそ、試合が中止になった。 → 雨が降ったので、試合が中止になった。（单纯的负面原因不用）
- 重点：〜とあれば
  - 意思：如果是……的话（就不惜）
  - 接续：名詞・普通形＋とあれば
  - Ａとあれば、Ｂ：如果是Ａ这样（特殊）的情况，那就（不惜）Ｂ
  - 常见：〜のためとあれば（只要是为了……）、〜の頼みとあれば（如果是……的请求）
  - 一句话：特别的条件とあれば + 不惜、只好。
  - 常错：雨とあれば、傘を持っていく。 → 雨なら、傘を持っていく。（普通的条件用「なら」）

  - [c] 夕焼けで空が赤みを___。　选项：帯びている / 隔てている / 踏ん張っている / 逃れている　答案：帯びている
