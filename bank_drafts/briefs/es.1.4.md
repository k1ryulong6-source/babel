# 单元简报：es.1.4 我的一天

单元目标：-ar/-er/-ir 现在时规则变位、自反动词、钟点与星期
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：-ar 动词现在时　题库已有 0 题
情境：hablas、estudio、trabajo、cocina：同一个动词，词尾一变，主语就变了。
新词：hablar、trabajar、estudiar、llamar、necesitar、comprar、tomar、escuchar、mirar、cocinar
搭配 / 表达：tomar un café、por la mañana / tarde / noche、¿Hablas español?
- 重点：-ar 动词现在时：去掉 -ar，按人称加词尾
  - hablar → habl- + o, as, a, amos, áis, an：
  - yo hablo　tú hablas　él / ella / usted habla
  - nosotros hablamos　vosotros habláis　ellos / ustedes hablan
  - 西语大约 80% 的动词是 -ar 动词，这一套词尾用得最多。
  - 一句话：-o, -as, -a, -amos, -áis, -an；主语一般省略，否定在动词前加 no。
  - 常错：Yo habla español. → Hablo español.（yo → -o，主语可省）
  - 常错：Ellos no habla inglés. → Ellos no hablan inglés.（ellos → -an）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] Nosotros ___ español.　选项：estudio / estudian / estudiamos / estudiáis　答案：estudiamos
  - [f] Yo ___ (necesitar) ayuda.　答案：necesito
  - [o] Trabajo por la mañana.

## 第 2 课（l = 2）：-er 与 -ir 动词　题库已有 0 题
情境：vivo、vivimos、comemos、lees：-er 和 -ir 动词。
新词：comer、beber、leer、aprender、vivir、escribir、abrir、responder、creer
搭配 / 表达：¿Dónde vives?、Creo que sí / no.、aprender a + inf.
- 重点：-er 和 -ir 动词：词尾几乎一样，只差两处
  - comer：como, comes, come, comemos, coméis, comen
  - vivir：vivo, vives, vive, vivimos, vivís, viven
  - 只在 nosotros（-emos / -imos）和 vosotros（-éis / -ís）不同；其余四个完全一样。
  - 和 -ar 对比：-ar 用 a（hablas），-er / -ir 用 e（comes, vives）。
  - 一句话：-er：-o -es -e -emos -éis -en；-ir 只把 -emos / -éis 换成 -imos / -ís。
  - 常错：Nosotros vivemos aquí. → Nosotros vivimos aquí.（-ir → -imos）
  - 常错：Tú comas mucho. → Tú comes mucho.（-er 用 e）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] Nosotros ___ mucho en clase.　选项：aprendí / aprendemos / aprendéis / aprenden　答案：aprendemos
  - [o] Aprendo a cocinar.
  - [tr] 我在学做饭。 → Aprendo a cocinar.

## 第 3 课（l = 3）：自反动词：起床、洗澡　题库已有 0 题
情境：me levanto、me ducho、me acuesto：这些动作“落在自己身上”，动词前要带 me。
新词：levantarse、ducharse、acostarse、desayunar、cenar、desayuno、almuerzo、cena
搭配 / 表达：todos los días、primero … luego …、Buen provecho.
- 重点：自反动词：动作落在自己身上，前面带 me / te / se
  - 不定式带 -se：levantarse 起床、ducharse 洗澡、acostarse 睡觉、llamarse 名叫、vestirse 穿衣
  - 变位时 se 跟着人称变，放在动词前：
  - me levanto　te levantas　se levanta　nos levantamos　os levantáis　se levantan
  - 同一个动词，去掉 se 意思不同：levantar 举起（别的东西）/ levantarse 起床（把自己“举起来”）
  - 一句话：me / te / se / nos / os / se + 变位动词。
  - 常错：Levanto a las siete. → Me levanto a las siete.（缺 me）
  - 常错：Yo se levanta. → Yo me levanto.（代词和词尾都跟着 yo 变）
- 重点：词干变化：acostarse → me acuesto
  - 有一批常用动词在重读的词干里变元音（nosotros、vosotros 不变）：
  - o → ue：acostarse → me acuesto, te acuestas… nos acostamos；poder → puedo；dormir → duermo
  - e → ie：querer → quiero；empezar → empiezo；pensar → pienso
  - e → i：pedir → pido；vestirse → me visto
  - 一句话：“靴子形”：yo、tú、él、ellos 变，nosotros、vosotros 不变。
  - 常错：Me acosto a las once. → Me acuesto a las once.（o → ue）
  - 常错：Nosotros nos acuestamos. → Nosotros nos acostamos.（nosotros 不变）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 吃晚饭是？　选项：desayunar / almorzar / cenar / comer　答案：cenar
  - [o] Me levanto a las siete.
  - [tr] 我们晚上和家人一起吃晚饭。 → Por la noche cenamos con la familia.

## 第 4 课（l = 4）：钟点与时间　题库已有 0 题
情境：Es la una / Son las ocho；“几点了”和“在几点”说法不同。
新词：hora、minuto、tarde、ahora、antes、después、luego、siempre、nunca、a veces
搭配 / 表达：¿A qué hora …?、en punto、Hasta luego.
- 重点：说时间：Es la una，Son las dos；“在几点”用 a
  - “现在几点”：Es la una（1 点用单数）；Son las dos / tres / … doce
  - 加分钟用 y：Son las tres y diez；一刻 y cuarto；半 y media
  - 差几分用 menos（下一个钟点减）：Son las cinco menos cuarto = 4:45
  - “在几点”用 a：La clase empieza a las nueve. ¿A qué hora…?
  - 上午 / 下午 / 晚上：de la mañana / de la tarde / de la noche
  - 一句话：Es la una / Son las …；在几点用 a；45 分说“下一点 menos cuarto”。
  - 常错：Son la una. → Es la una.（1 点用单数）
  - 常错：Es las dos. → Son las dos.（）
- 重点：频率：siempre、a veces、nunca
  - siempre 总是　a menudo 经常　a veces 有时　nunca 从不
  - nunca 放动词前：Nunca bebo café.；放动词后要加 no：No bebo café nunca.（双重否定在西语里是正确的）
  - 一句话：nunca + 动词，或 no + 动词 + nunca。
  - 常错：Bebo nunca café. → Nunca bebo café. / No bebo nunca café.（放后面要加 no）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Siempre desayuno a las siete.
  - [tr] 我总是七点吃早饭。 → Siempre desayuno a las siete.

## 第 5 课（l = 5）：星期与一周　题库已有 0 题
情境：el sábado（这个周六）和 los sábados（每个周六）：一个冠词，意思就不同。
新词：lunes、martes、miércoles、jueves、viernes、sábado、domingo、fin de semana、hoy、semana
搭配 / 表达：¿Qué día es hoy?、el próximo …、¡Buen fin de semana!
- 重点：el lunes = 这个周一，los lunes = 每个周一；不加 en
  - 星期名小写、都是阳性：el lunes … el domingo
  - “在周一”：直接 el lunes（不加介词 en）：El sábado trabajo.
  - “每周一”：los lunes：Los sábados no trabajo.
  - lunes 到 viernes 单复数同形（el / los lunes）；sábado、domingo 复数加 s。
  - 问星期：¿Qué día es hoy? — Hoy es martes.（说今天星期几时不加冠词）
  - 一句话：el + 星期 = 那一天；los + 星期 = 每周那天；不加 en。
  - 常错：En sábado trabajo. → El sábado trabajo.（不加 en）
  - 常错：Hoy es el martes. → Hoy es martes.（说今天星期几不加冠词）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 星期三是？　选项：martes / miércoles / jueves / lunes　答案：miércoles
  - [f] ¡Buen fin de ___!　答案：semana
  - [o] Hoy es martes.
