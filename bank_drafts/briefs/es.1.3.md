# 单元简报：es.1.3 家人与身边的东西

单元目标：tener、物主形容词、形容词性数一致、hay、数字到 100
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：家人与 tener　题库已有 0 题
情境：tener 是西语里最忙的动词之一：有、几岁、饿、渴、冷、必须……都靠它。
新词：familia、padre、madre、hijo、hermano、abuelo、tío、primo、esposo、tener
搭配 / 表达：tener hambre、tener que + inf.、¿Tienes hermanos?
- 重点：tener：有，以及“有饿、有冷”
  - tener 现在时：tengo, tienes, tiene, tenemos, tenéis, tienen（yo 形不规则，e → ie）
  - “有”：Tengo dos hermanos. ¿Tienes coche?
  - 身体感觉用 tener + 名词：tener hambre 饿、sed 渴、frío 冷、calor 热、sueño 困、prisa 急、miedo 怕
  - tener que + 动词原形 = 必须：Tengo que trabajar.
  - 一句话：饿渴冷热困急怕：tener + 名词；必须：tener que + 原形。
  - 常错：Estoy hambre. → Tengo hambre.（）
  - 常错：Tengo muy hambre. → Tengo mucha hambre.（hambre 是名词，用 mucha）
- 重点：阳性复数可以包括男女：padres、hermanos、hijos
  - padres = 父母（不只是“爸爸们”）
  - hermanos = 兄弟姐妹　hijos = 子女　abuelos = 祖父母
  - 只要一群人里有男有女，就用阳性复数；只有全是女性才用阴性复数（hermanas）。
  - 一句话：padres 父母，hermanos 兄弟姐妹，hijos 子女。
  - 常错：mis padre y madre → mis padres（）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Tengo que estudiar.

## 第 2 课（l = 2）：物主形容词　题库已有 0 题
情境：mi、nuestro、nuestros：西语的“我的、我们的”要跟着后面的名词变。
新词：mi、tu、su、nuestro、vuestro、bebé、vecino、jardín、gato
搭配 / 表达：Este es mi …、Esta es mi …、¡Qué bonito!
- 重点：物主形容词跟着后面的名词变，不跟“主人”变
  - mi / mis 我的　tu / tus 你的　su / sus 他的 / 她的 / 您的 / 他们的
  - nuestro / nuestra / nuestros / nuestras 我们的　vuestro… 你们的
  - 单复数看后面的名词：mis libros（我的几本书）；nuestro / vuestro 还要看名词的性：nuestra casa
  - 一句话：物主形容词看后面的名词：mis libros，nuestra casa。
  - 常错：mi padres → mis padres（看名词：复数）
  - 常错：nuestro casa → nuestra casa（casa 阴性）
- 重点：este / ese / aquel：这个、那个、远处那个
  - este / esta / estos / estas：这（离我近）
  - ese / esa / esos / esas：那（离你近或不远）
  - aquel / aquella / aquellos / aquellas：那（离我们都远）
  - 介绍人：Este es mi hermano. Esta es mi madre.（跟着被介绍的人变性）
  - 一句话：este 这、ese 那、aquel 远处那，都跟名词变性数。
  - 常错：Este es mi madre. → Esta es mi madre.（madre 阴性）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Este es mi hermano.
  - [tr] 这是我的邻居。 → Este es mi vecino.

## 第 3 课（l = 3）：形容词的性数一致　题库已有 0 题
情境：casas nuevas、hermanos altos：形容词放在名词后面，还要跟名词一起变。
新词：grande、pequeño、nuevo、viejo、joven、alto、bajo、bonito、guapo
搭配 / 表达：¿Cómo es …?、muy + adj.、un poco
- 重点：形容词放在名词后，性数跟着名词变
  - 位置：一般放在名词后面：una casa grande, un coche nuevo, los chicos altos
  - -o 结尾的形容词四种形式：alto, alta, altos, altas
  - -e 或辅音结尾的只变数：grande / grandes，joven / jóvenes，azul / azules
  - 用 ser 描述人或物的特征：¿Cómo es…? — Es alto y simpático.
  - 一句话：名词 + 形容词，性数全部对齐。
  - 常错：una grande casa → una casa grande（一般放后面）
  - 常错：las casas nuevo → las casas nuevas（跟着变）
- 重点：放在名词前会变形、变意思：buen、gran
  - bueno / malo 在阳性单数名词前去掉 o：un buen amigo，un mal día
  - grande 在单数名词前变 gran，意思变成“伟大的”：un gran hombre（伟人）/ un hombre grande（大个子的男人）
  - primero / tercero 在阳性单数名词前也去 o：el primer día
  - 一句话：buen / mal / gran / primer：放在单数名词前的短形式。
  - 常错：un bueno amigo → un buen amigo（）
  - 常错：una buen amiga → una buena amiga（只有阳性单数才去 o）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Mi casa es un poco pequeña.
  - [tr] 我的兄弟们很高。 → Mis hermanos son altos.

## 第 4 课（l = 4）：hay：某处有……　题库已有 0 题
情境：hay（有）和 está（在）：问“有没有”和问“在哪儿”用的动词不同。
新词：habitación、cocina、baño、dormitorio、salón、puerta、ventana、silla、cama、sofá
搭配 / 表达：¿Hay … por aquí?、al lado de、en casa
- 重点：hay 和 estar：“有什么”和“在哪儿”
  - hay（不变形）= 某处有（介绍新东西）：Hay un sofá en el salón. Hay dos baños. ¿Hay un banco por aquí?
  - estar = 某个特定的东西在哪：El sofá está en el salón. ¿Dónde está el baño?
  - 看冠词：hay 后面接 un / una / 数字 / 不带冠词的名词；estar 的主语带 el / la / mi 这类“确定的”词。
  - 一句话：un / 数字 → hay；el / mi → estar。
  - 常错：Hay el baño al fondo. → El baño está al fondo.（特定的东西用 estar）
  - 常错：En la cocina está una mesa. → En la cocina hay una mesa.（新东西用 hay）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] La cocina está al lado ___ salón.　答案：del
  - [o] ¿Hay un baño por aquí?
  - [tr] 卧室里有一张床和两把椅子。 → En el dormitorio hay una cama y dos sillas.

## 第 5 课（l = 5）：数字 11–100　题库已有 0 题
情境：cuarenta y cinco、treinta y dos：西语数字 30 以后像中文一样“几十 + 几”。
新词：once、doce、trece、catorce、quince、veinte、treinta、cuarenta、cincuenta、cien
搭配 / 表达：¿Cuánto es?、Son … euros.、más o menos
- 重点：11–100 的组合规律
  - 11–15 单独记：once, doce, trece, catorce, quince
  - 16–19、21–29 写成一个词：dieciséis, diecisiete…；veintiuno, veintidós, veintitrés…
  - 30 以后用 y 连接、分开写：treinta y uno, cuarenta y cinco, noventa y nueve
  - 整十：veinte, treinta, cuarenta, cincuenta, sesenta, setenta, ochenta, noventa；100 = cien（101 起是 ciento uno）
  - 一句话：16–29 连写，30 以后“几十 y 几”；13 / 30、15 / 50 听清楚。
  - 常错：veinte y dos → veintidós（21–29 连写）
  - 常错：cuarenta cinco → cuarenta y cinco（30 以后要 y）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Son quince euros.
  - [tr] 一共多少钱？ → ¿Cuánto es en total?
