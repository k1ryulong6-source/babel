# 单元简报：es.1.6 吃喝与购物

单元目标：gustar、querer/poder、点餐、价格、指示词与颜色
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：gustar：我喜欢　题库已有 0 题
情境：Me gusta el chocolate / Me gustan las frutas：西语的“喜欢”结构和中文正好相反。
新词：gustar、fruta、carne、pescado、verdura、chocolate、helado、té、fiesta
搭配 / 表达：A mí también.、A mí tampoco.、Me encanta …
- 重点：gustar：“某物让我喜欢”，喜欢的东西才是主语
  - 结构：(a + 人) + me / te / le / nos / os / les + gusta(n) + 喜欢的东西
  - 喜欢的东西是单数或动词原形 → gusta：Me gusta el café. Me gusta leer.
  - 喜欢的东西是复数 → gustan：Me gustan las frutas.
  - 名词前要加定冠词：Me gusta el chocolate（不说 me gusta chocolate）
  - 一句话：喜欢的东西单数 gusta、复数 gustan；人用 me / te / le / nos / os / les。
  - 常错：Yo gusto el café. → Me gusta el café.（主语是 el café）
  - 常错：Me gusta las frutas. → Me gustan las frutas.（复数用 gustan）
- 重点：回应：A mí también / A mí tampoco
  - 对方说喜欢，你也喜欢：A mí también.
  - 对方说不喜欢，你也不喜欢：A mí tampoco.
  - 意见相反：A mí sí.（我喜欢）/ A mí no.（我不喜欢）
  - 一句话：肯定 → también，否定 → tampoco；意见相反 a mí sí / no。
  - 常错：— No me gusta. — A mí también. → A mí tampoco.（否定跟 tampoco）
  - 常错：Yo también.（回应 gustar） → A mí también.（）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Me encanta el helado.

## 第 2 课（l = 2）：在餐厅点餐　题库已有 0 题
情境：quiero、puede：点餐和请求的两个关键动词。
新词：querer、poder、menú、cuenta、camarero、plato、vaso、botella、postre
搭配 / 表达：La cuenta, por favor.、Para mí, …、¿Qué me recomienda?
- 重点：querer 和 poder：词干变化动词
  - querer 想要（e → ie）：quiero, quieres, quiere, queremos, queréis, quieren
  - poder 能（o → ue）：puedo, puedes, puede, podemos, podéis, pueden
  - 后面都直接接动词原形：Quiero comer. ¿Puedes venir?
  - 一句话：quiero / puedo；nosotros 是 queremos / podemos。
  - 常错：Nosotros puedemos. → Nosotros podemos.（nosotros 不变）
  - 常错：Yo quero agua. → Yo quiero agua.（e → ie）
- 重点：点餐要礼貌：quería、para mí、¿me pone…?
  - Quería una ensalada, por favor.（用过去未完成时，比 quiero 更客气）
  - Para mí, el pescado.（我要鱼）
  - ¿Me pone…?（西班牙常用，请给我……）　¿Me trae…?（能给我拿……吗）
  - 结账：La cuenta, por favor.
  - 一句话：Quería… / Para mí… / ¿Me pone…? / La cuenta, por favor.
  - 常错：Dame la cuenta.（对服务员） → La cuenta, por favor.（命令式太冲）

## 第 3 课（l = 3）：常见食物　题库已有 0 题
情境：zumo de naranja、pan con tomate、un poco de jamón：食物名字里的 de 和 con。
新词：pan、leche、huevo、galleta、pollo、sopa、ensalada、patata、tomate
搭配 / 表达：café con leche、un poco de …、¡Qué rico está!
- 重点：de 表示材料或口味；不可数的食物不加 un
  - 名词 + de + 名词：zumo de naranja（橙汁）、sopa de tomate、bocadillo de jamón —— 后一个名词说明“什么做的、什么口味”
  - con = 加了 / 配着：café con leche，pan con tomate
  - 不可数的食物不加 un / una：Como arroz. Bebo leche.；说数量用 un poco de、mucho / mucha
  - 一句话：主名词 + de + 材料；un poco de + 不可数。
  - 常错：naranja zumo → zumo de naranja（修饰在后，用 de）
  - 常错：Quiero un poco leche. → Quiero un poco de leche.（un poco de）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] Yo ___ arroz con pollo.　选项：como / bebo / tomo un / es　答案：como
  - [c] 西班牙人一般几点吃晚饭？　选项：18 点 / 21 点以后 / 12 点 / 16 点　答案：21 点以后
  - [tr] 真好吃！ → ¡Qué rico está!

## 第 4 课（l = 4）：购物与价格　题库已有 0 题
情境：cuesta 和 cuestan：问价格也要看东西是单数还是复数。
新词：costar、precio、dinero、euro、caro、barato、pagar、tarjeta、zapato、bolso
搭配 / 表达：¿Cuánto cuesta?、con tarjeta / en efectivo、Es muy caro.
- 重点：¿Cuánto cuesta / cuestan?：跟着东西变
  - costar（花费，o → ue）：东西是主语
  - 单数：¿Cuánto cuesta este bolso?　复数：¿Cuánto cuestan estos zapatos?
  - 问总价：¿Cuánto es?（一共多少）
  - 付款：pagar con tarjeta（刷卡）/ en efectivo（现金）
  - 一句话：单数 cuesta、复数 cuestan；con tarjeta / en efectivo。
  - 常错：¿Cuánto cuesta los zapatos? → ¿Cuánto cuestan los zapatos?（）
  - 常错：pagar en tarjeta → pagar con tarjeta（）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] ¿Cuánto ___? — Son veinte euros. (一共)　答案：es
  - [o] ¿Puedo pagar con tarjeta?
  - [tr] 太贵了。 → Es muy caro.

## 第 5 课（l = 5）：这个、那个与颜色　题库已有 0 题
情境：esto / eso（中性）和 este / esta：指不知名的东西用中性。
新词：este、ese、esto、eso、azul、verde、blanco、negro、amarillo
搭配 / 表达：¿De qué color es?、Me lo llevo.、Eso es.
- 重点：中性的 esto / eso：指“这东西”“这件事”
  - este / esta / estos / estas + 名词（或代替已知的名词）：este libro, esta camisa
  - esto / eso / aquello（中性，没有复数）：
  - ① 指不知道名字的东西：¿Qué es esto?
  - ② 指一件事、一句话：Eso es verdad. No entiendo esto.
  - 一句话：不知名的东西、一件事 → esto / eso。
  - 常错：¿Qué es este? → ¿Qué es esto?（不知道是什么，用中性）
- 重点：颜色是形容词：跟着名词变
  - -o 结尾的颜色四种形式：blanco / blanca / blancos / blancas；negro, rojo, amarillo 同理
  - -e 或辅音结尾只变数：verde / verdes，azul / azules，marrón / marrones
  - 问颜色：¿De qué color es…?
  - 一句话：名词 + 颜色，性数一致。
  - 常错：una camisa blanco → una camisa blanca（）
  - 常错：los coches verdos → los coches verdes（）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Me lo llevo.
