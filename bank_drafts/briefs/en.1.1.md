# 单元简报：en.1.1 字母与元音

单元目标：26 个字母、短元音、长元音、双元音；最常用的生活词
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：26 个字母　题库已有 0 题
情境：英语里经常要把名字、地址、邮箱一个字母一个字母地拼出来。这一课把 26 个字母的“名字”念准。
新词：say、what、go、can、who、get、if、would、all、make、about、know
搭配 / 表达：How do you spell …?、capital letter、What does … mean?
- 重点：字母的“名字”和它在单词里的“发音”不是一回事
  - 每个字母都有一个名字（拼写时念的）：A /eɪ/、B /biː/、C /siː/……
  - 但字母在单词里常常读另一个音：字母 A 的名字是 /eɪ/，在 cat 里却读 /æ/；字母 C 在 cat 里读 /k/。
  - 最容易念错的几组名字：G /dʒiː/ 和 J /dʒeɪ/；E /iː/ 和 I /aɪ/；A /eɪ/ 和 R /ɑːr/；W /ˈdʌbəljuː/；Z 美式 /ziː/、英式 /zed/。
  - 一句话：拼写念名字，读词念发音；E /iː/、I /aɪ/、G /dʒiː/、J /dʒeɪ/ 别念反。
  - 常错：E 读成 /aɪ/ → E /iː/（像“衣”）（和字母 I 念反了）
  - 常错：G 读成 /dʒeɪ/ → G /dʒiː/（/dʒeɪ/ 是 J）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 下面哪个是元音字母？　选项：b / e / k / t　答案：e
  - [c] 字母 G 的读音是？　选项：/dʒiː/ / /dʒeɪ/ / /ɡiː/ / /ɡeɪ/　答案：/dʒiː/
  - [c] 字母 I 的读音是？　选项：/iː/ / /aɪ/ / /eɪ/ / /ɪ/　答案：/aɪ/

## 第 2 课（l = 2）：短元音：cat, bed, sit, hot, cup　题库已有 0 题
情境：这三句里几乎全是“短元音”。中国学生英语听起来不地道，最大的原因就在这几个短元音上。
新词：will、up、time、there、year、so、think、when、which、some、people、take
搭配 / 表达：a lot of、look at、sit down
- 重点：/æ/ 和 /e/：bad 不是 bed
  - /æ/：cat, bad, map, bag —— 嘴张得很大，嘴角往两边拉，舌头压低，像“哎”和“啊”之间、又扁又开。
  - /e/：bed, red, pen —— 嘴只半开，像中文“哎”。
  - 一句话：/æ/ 嘴张大往两边拉，/e/ 只半开。
  - 常错：bad 读成 /bed/ → bad /bæd/（嘴要张大）
  - 常错：man 和 men 读成一样 → man /mæn/，men /men/（单复数全靠这个元音区分）
- 重点：/ɪ/ 和 /iː/：ship 不是 sheep
  - /ɪ/：sit, ship, fish, it —— 短、松，嘴唇放松，舌头不用力，比“衣”更靠近“诶”一点。
  - /iː/：seat, sheep, eat, see —— 长、紧，嘴角往两边拉（像微笑），舌头用力，声音拉长。
  - 一句话：/ɪ/ 短而松，/iː/ 长而紧（嘴角拉开）。
  - 常错：ship 读成 /ʃiːp/ → ship /ʃɪp/，短而放松（读成 sheep 了）
  - 常错：it 读成“衣特” → it /ɪt/，短促（）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] cat 中的 a 读？　选项：/æ/ / /eɪ/ / /ɑː/ / /e/　答案：/æ/
  - [c] 哪个单词的元音和 bed 一样？　选项：bad / red / bid / bud　答案：red
  - [c] 哪个单词含 /ɪ/？　选项：sit / seat / set / sat　答案：sit

## 第 3 课（l = 3）：长元音与不发音的 e　题库已有 0 题
情境：注意 like、take、time、home、cute：结尾都有一个不发音的 e。这个 e 不出声，却改变了前面元音的读法。
新词：out、into、just、see、come、could、now、than、like、other、how、then
搭配 / 表达：take a photo、on time、go home
- 重点：词尾不发音的 e：让前面的元音“念自己的名字”
  - 「元音 + 辅音 + e」结尾时，末尾的 e 不发音，前面的元音读字母名（长音）：
  - cap /kæp/ → cape /keɪp/　kit /kɪt/ → kite /kaɪt/
  - hop /hɒp/ → hope /həʊp/　cut /kʌt/ → cute /kjuːt/
  - 一句话：元音 + 辅音 + e：e 不读，前面元音读字母名。
  - 常错：make 读成 /meɪkə/ → make /meɪk/（词尾 e 不发音）
  - 常错：hope 读成 /hɒp/ → hope /həʊp/（o_e 读字母名 /əʊ/）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] make 中的 a 读？　选项：/æ/ / /eɪ/ / /ɑː/ / /e/　答案：/eɪ/
  - [c] 哪个单词的 o 读 /əʊ/？　选项：hot / not / home / top　答案：home
  - [f] Let's go ___ — it's late.　答案：home

## 第 4 课（l = 4）：双元音　题库已有 0 题
情境：where、house、now、near、know、way、go —— 每个词的元音都要“滑”。
新词：more、want、way、look、first、also、new、because、day、use、man、find
搭配 / 表达：right now、find out、by the way
- 重点：双元音要“滑”：/eɪ/ 和 /əʊ/ 不是“诶”和“欧”
  - 双元音由一个元音滑到另一个元音，口型必须变：
  - /eɪ/ day, say, make：从 /e/ 滑到 /ɪ/，嘴角慢慢拉开
  - /əʊ/（美式 /oʊ/）go, know, home：从 /ə/ 滑到 /ʊ/，嘴唇慢慢收圆
  - /aɪ/ my, time；/aʊ/ now, house；/ɔɪ/ boy, oil
  - 一句话：双元音口型一定要变；ow 有两读：now /aʊ/、know /əʊ/。
  - 常错：late 读成 /let/ → late /leɪt/（没滑到 /ɪ/）
  - 常错：know 读成 /naʊ/ → know /nəʊ/（ow 在 know 里读 /əʊ/）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] day 中 ay 读？　选项：/æ/ / /eɪ/ / /aɪ/ / /e/　答案：/eɪ/
  - [c] high 中 igh 读？　选项：/ɪ/ / /aɪ/ / /iː/ / /eɪ/　答案：/aɪ/
  - [c] 哪个单词含 /ɔɪ/？　选项：boy / buy / bay / bow　答案：boy

## 第 5 课（l = 5）：元音组合与单元复习　题库已有 0 题
新词：here、thing、give、many、well、only、tell、very、even、back、any、good
搭配 / 表达：look for、at first、thank you for …
- 重点：同样的字母，不同的读音：oo、ea、词尾 er
  - oo：多读长音 /uː/ —— food, school, moon；但 book, look, good, foot 读短音 /ʊ/。
  - ea：多读 /iː/ —— eat, read, team；但 head, bread, ready 读 /e/。
  - 词尾不重读的 er / or：弱读成轻轻的 /ə/ —— teacher, doctor, computer。
  - 一句话：oo：food 长、book 短；ea：eat /iː/、head /e/；词尾 er 轻读 /ə/。
  - 常错：good 读成 /ɡuːd/ → good /ɡʊd/（short oo）
  - 常错：head 读成 /hiːd/ → head /hed/（ea 的例外）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 哪个单词含 /ɜː/？　选项：car / her / for / here　答案：her
  - [c] 听音，选出听到的词。　选项：eat / it　答案：eat
  - [f] I'm looking ___ my phone.　答案：for
