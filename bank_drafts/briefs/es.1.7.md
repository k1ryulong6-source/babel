# 单元简报：es.1.7 计划与天气

单元目标：ir a + 不定式、词干变化动词、不规则 yo 形式、天气与季节、爱好
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：ir a + 不定式：打算做　题库已有 0 题
情境：voy a comprar、vamos a viajar：西语口语里最常用的将来说法。
新词：cumpleaños、regalo、vacaciones、playa、montaña、viajar、pasaporte、maleta
搭配 / 表达：¿Qué vas a hacer …?、¡Feliz cumpleaños!、Tengo planes.
- 重点：ir a + 动词原形：打算做、马上要做
  - 结构：ir（变位）+ a + 动词原形：Voy a comprar un regalo. ¿Qué vas a hacer?
  - voy a / vas a / va a / vamos a / vais a / van a + 原形
  - 常和时间词连用：mañana, esta tarde, este fin de semana, el próximo mes, la semana que viene
  - Vamos a + 原形 也能表示“我们来……吧”：¡Vamos a bailar!
  - 一句话：voy / vas / va … + a + 原形。
  - 常错：Voy comprar. → Voy a comprar.（不能漏 a）
  - 常错：Yo ir a viajar. → Voy a viajar.（ir 要变位）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] “生日快乐”：　选项：¡Buen cumpleaños! / ¡Feliz cumpleaños! / ¡Feliz fiesta! / ¡Buen viaje!　答案：¡Feliz cumpleaños!
  - [o] ¿Qué vas a hacer este fin de semana?
  - [tr] 生日快乐！ → ¡Feliz cumpleaños!

## 第 2 课（l = 2）：词干变化：e → ie, o → ue　题库已有 0 题
情境：empieza、vuelvo、prefieres、pienso：这些动词的词干会变。
新词：empezar、pensar、preferir、cerrar、volver、dormir、jugar、entender、recordar
搭配 / 表达：No entiendo.、Pienso que …、¿Prefieres … o …?
- 重点：“靴子动词”：e → ie，o → ue，u → ue
  - e → ie：empezar → empiezo；pensar → pienso；preferir → prefiero；entender → entiendo；cerrar → cierro
  - o → ue：volver → vuelvo；dormir → duermo；recordar → recuerdo；poder → puedo
  - u → ue（只有 jugar）：juego
  - nosotros、vosotros 不变：empezamos, volvemos, jugamos
  - 一句话：靴子里的四格变，nosotros / vosotros 不变。
  - 常错：Yo dormo ocho horas. → Yo duermo ocho horas.（o → ue）
  - 常错：Nosotros vuelvemos. → Nosotros volvemos.（nosotros 不变）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] ¿___ (preferir, tú) té o café?　答案：Prefieres
  - [tr] 你喜欢茶还是咖啡？ → ¿Prefieres té o café?

## 第 3 课（l = 3）：e → i 与“我”的不规则形式　题库已有 0 题
情境：hago、salgo、conozco、sé：有一批动词只有“我”这一格不规则。
新词：pedir、repetir、hacer、poner、salir、decir、venir、saber、conocer
搭配 / 表达：¿Puede repetir, por favor?、No sé.、¿Qué haces?
- 重点：只有 yo 不规则的动词：hago, salgo, pongo…
  - 这些动词只有 yo 形式特别，其余五格完全规则：
  - hacer → hago（haces, hace…）　poner → pongo　salir → salgo　traer → traigo
  - saber → sé　conocer → conozco　dar → doy　ver → veo
  - yo 不规则 + 词干变化：tener → tengo, tienes；venir → vengo, vienes；decir → digo, dices
  - 一句话：-go 家族：hago, pongo, salgo, traigo, tengo, vengo, digo；另记 sé, conozco, doy, veo。
  - 常错：Yo haco → Yo hago（）
  - 常错：Yo salo → Yo salgo（）
- 重点：saber 和 conocer：知道 / 会，认识 / 去过
  - saber：知道信息、事实；会做某事（+ 原形）—— No sé dónde vive. Sé nadar.
  - conocer：认识人、熟悉 / 去过地方、知道某个作品 —— Conozco a tu hermana. ¿Conoces Madrid?
  - conocer 后面接人时要加 a：Conozco a tu hermana.
  - 一句话：saber 事实 / 会做；conocer 人 / 地方（人前加 a）。
  - 常错：Sé a tu hermana. → Conozco a tu hermana.（认识人用 conocer）
  - 常错：Conozco nadar. → Sé nadar.（会做某事用 saber）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] ¿Puede repetir, por favor?

## 第 4 课（l = 4）：天气与季节　题库已有 0 题
情境：hace calor、llueve、está nublado：说天气要用 hacer，不用 ser 或 estar。
新词：calor、frío、sol、lluvia、primavera、verano、otoño、invierno、tiempo
搭配 / 表达：¿Qué tiempo hace?、Hace buen tiempo.、Está lloviendo.
- 重点：说天气用 hacer；下雨下雪有专门的动词
  - hace + 名词：Hace calor（热）/ frío（冷）/ sol（出太阳）/ viento（刮风）/ buen tiempo / mal tiempo
  - llover 下雨（ue）：Llueve. / Está lloviendo（正在下）；nevar 下雪（ie）：Nieva.
  - hay niebla（有雾）；está nublado（多云）
  - 问天气：¿Qué tiempo hace?
  - 一句话：天气 hace + 名词；人的感觉 tener + 名词；llueve / nieva。
  - 常错：Es calor. → Hace calor.（）
  - 常错：Hace muy calor. → Hace mucho calor.（calor 是名词）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] En ___ hace calor. (夏天)　答案：verano
  - [o] Hace buen tiempo.

## 第 5 课（l = 5）：爱好与频率　题库已有 0 题
情境：jugar al fútbol、dos veces a la semana、no me gusta nada：说爱好的几个固定说法。
新词：deporte、fútbol、nadar、bailar、cantar、descansar、gimnasio、piscina、andar
搭配 / 表达：en mi tiempo libre、una vez a la semana、hacer deporte
- 重点：jugar al + 球类；hacer deporte；频率说法
  - jugar al + 球类 / 游戏：jugar al fútbol, al tenis（jugar a + el = al）
  - tocar + 乐器：tocar la guitarra（不用 jugar）
  - hacer deporte 做运动；ir al gimnasio 去健身房
  - 频率：todos los días 每天，una vez a la semana 一周一次，dos veces al mes 一月两次，casi nunca 几乎不
  - 一句话：jugar al + 球；tocar + 乐器；X veces a la semana。
  - 常错：Juego fútbol. → Juego al fútbol.（）
  - 常错：Juego la guitarra. → Toco la guitarra.（乐器用 tocar）
- 重点：强调“一点也不”：no … nada；gustar 的程度
  - Me gusta mucho 很喜欢　Me encanta 超爱　No me gusta mucho 不太喜欢　No me gusta nada 一点也不喜欢
  - nada 放动词后时，动词前要有 no（双重否定，和 nunca 一样）
  - 一句话：No me gusta nada：一点也不喜欢。
  - 常错：Me gusta nada. → No me gusta nada.（要有 no）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Voy al gimnasio dos veces a la semana.
