## 第 1 课（l = 1）：会社と人事　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面先讲词，再把两个文型讲透。
新词：抜擢、兼務、出世、輩出、逸材、即戦力、窓際、片腕、大御所、古巣、新参、世襲、失態、始末書、登竜門
搭配 / 表达：頭角を現す、肩を並べる、足を引っ張る、腕を振るう
- 重点：〜かたわら
  - 意思：一边……一边（从事其他活动）
  - 接续：名詞＋の・動詞辞書形＋かたわら
  - 一句话：本业のかたわら副业 —— 长期并行；同一时刻的动作用「ながら」。
  - 常错：テレビを見るかたわらご飯を食べた。 → テレビを見ながらご飯を食べた。（瞬间的同时动作用ながら）
  - 常错：会社員かたわら → 会社員のかたわら（名词后要加の）
- 重点：〜を押して
  - 意思：不顾……；冒着……
  - 接续：名詞（病・反対・困難）＋を押して
  - 一句话：病・反対・困難を押して + 坚持去做某事。
  - 常错：雨を押して傘をさした。 → 雨の中、傘をさした。（没有“克服障碍坚持做”的意思）
  - 常错：病気を押しで出勤した。 → 病気を押して出勤した。（て形）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 新人を大胆に___した。　选项：抜擢 / 失態 / 兼務 / 窓際　答案：抜擢
  - [c] この大学は多くの研究者を___してきた。　选项：輩出 / 抜擢 / 新参 / 世襲　答案：輩出
  - [c] 「窓際族」とは？　选项：窓の近くで働く人 / 仕事を与えられず閑職にいる社員 / 景色の好きな人 / 受付係　答案：仕事を与えられず閑職にいる社員

## 第 2 课（l = 2）：経営と業績　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面先讲词，再把两个文型讲透。
新词：計上、粉飾、補填、工面、元手、勝算、得策、秘策、正攻法、定石、苦肉、万策、品薄、客足、閑散
搭配 / 表达：背水の陣、起死回生、一石二鳥、試行錯誤
- 重点：〜をもってしても
  - 意思：即使凭借……也（不能）
  - 接续：名詞＋をもってしても
  - 「をもって」是“凭借”；「しても」是“即使”。合起来：即使凭借这么厉害的东西，也……
  - 后面一定接否定或困难：〜できない、〜難しい、〜不可能だ。
  - 一句话：强大的手段をもってしても + 否定 / 困难。
  - 常错：最新技術をもってしても、簡単に解決できた。 → 最新技術をもってすれば、簡単に解決できた。（正面结果用「もってすれば」）
- 重点：〜いかんでは / 〜いかんだ
  - 意思：根据……如何（有可能）；视……而定
  - 接续：名詞（＋の）＋いかんで（は）、いかんによっては；〜いかんだ
  - 「いかん」（如何）＝“怎么样”。
  - Ａいかんでは、Ｂ：视Ａ的情况，有可能Ｂ（Ｂ多为极端结果）
  - Ｃはａいかんだ：Ｃ取决于ａ：成否は努力いかんだ。
  - 否定形「〜いかんにかかわらず / いかんを問わず」：不论……如何
  - 一句话：名詞（の）いかんでは + 可能出现的结果；〜はＡいかんだ = 取决于Ａ。
  - 常错：天気いかんで、ピクニックに行くかもしれない。（口语） → 天気次第で…（日常口语用「次第」更自然）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 人気商品が___状態だ。　选项：品薄 / 閑散 / 元手 / 秘策　答案：品薄
  - [c] 開業資金を何とか___した。　选项：工面 / 粉飾 / 計上 / 勝算　答案：工面
  - [c] このまま争うのは___ではない。　选项：得策 / 定石 / 客足 / 補填　答案：得策

## 第 3 课（l = 3）：交渉と取引　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面先讲词，再把两个文型讲透。
新词：折衷、折半、快諾、内諾、固辞、違約、先方、齟齬、斡旋、稟議、決裁、査収、照会、一考、異存
搭配 / 表达：腹を割る、足元を見る、手を打つ、首を縦に振る
- 重点：〜に先立ち / 〜に先立って
  - 意思：在……之前（先做）
  - 接续：名詞・動詞辞書形＋に先立ち（に先立って）
  - 在重大的事之前，先做准备性的事。前项多是：開会・契約・発売・公開・試合・選挙。
  - 修饰名词时：〜に先立つ＋名詞（試合に先立つ記者会見）
  - 一句话：重大的事＋に先立ち，先做准备。
  - 常错：ご飯を食べるに先立ち、手を洗う。 → ご飯を食べる前に手を洗う。（日常小事用「前に」）
- 重点：〜次第です
  - 意思：是……这么个情况；特此……
  - 接续：普通形・この＋次第です
  - 说明事情的来龙去脉：“是这么个情况”“特此……”
  - 普通形・この＋次第です：〜することになった次第です／という次第です
  - 邮件、致辞里用来收尾说明：ご連絡する次第です（特此联络）
  - 一句话：说明原委收尾 〜次第です；取决于「次第で」；一……就「ます形＋次第」。
  - 常错：天気次第です、行きます。 → 天気次第で行くかどうか決めます。（“取决于”是「次第で」）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 出演を依頼したところ、___してくれた。　选项：快諾 / 固辞 / 違約 / 照会　答案：快諾
  - [c] 交通費は二人で___しよう。　选项：折半 / 折衷 / 斡旋 / 稟議　答案：折半
  - [c] 資料を添付しましたので、ご___ください。　选项：査収 / 異存 / 先方 / 内諾　答案：査収

## 第 4 课（l = 4）：働き方と心構え　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面先讲词，再把两个文型讲透。
新词：研鑽、精進、尽力、奔走、忙殺、貫徹、完遂、踏襲、習熟、会得、鼓舞、本腰、度胸、底力、修羅場
搭配 / 表达：骨が折れる、手が回らない、猫の手も借りたい、身を粉にする
- 重点：〜てからというもの
  - 意思：自从……以后（一直）
  - 接续：動詞て形＋からというもの
  - 動詞て形＋からというもの：自从……以后，（一直）……
  - 后项是此后持续的变化或状态：〜ようになった、〜続けている、〜ばかりだ。
  - 一句话：てからというもの + 持续的变化（≠ 一次性的事、意志）。
  - 常错：日本に来てからというもの、一度富士山に登った。 → 日本に来てから、一度富士山に登った。（一次性的事不能用）
- 重点：〜にかまけて
  - 意思：只顾……而（忽视别的）
  - 接续：名詞＋にかまけて
  - 名詞＋にかまけて：只顾着……（结果疏忽了别的）
  - 后项是被忽略的事，多带反省、后悔、责备：〜をおろそかにする、〜を怠る、〜ない。
  - 一句话：Ａにかまけて + 疏忽了Ｂ（后悔、反省）。
  - 常错：研究にかまけて、ノーベル賞を取った。 → 研究に打ち込んで、ノーベル賞を取った。（正面结果不用「かまけて」）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 彼は資金集めに___した。　选项：奔走 / 踏襲 / 会得 / 修羅場　答案：奔走
  - [c] 年末は業務に___されている。　选项：忙殺 / 貫徹 / 鼓舞 / 本腰　答案：忙殺
  - [c] 前任者のやり方を___する。　选项：踏襲 / 研鑽 / 度胸 / 精進　答案：踏襲

## 第 5 课（l = 5）：複合動詞　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面先讲词，再把两个文型讲透。
新词：請け負う、手がける、繰り広げる、見合わせる、見越す、持ちかける、織り込む、差し控える、食い下がる、詰め寄る、乗っ取る、立ちはだかる、掛け離れる、見計らう、取りこぼす
搭配 / 表达：二の足を踏む、先手を打つ、後手に回る、見切りを付ける
- 重点：〜に越したことはない
  - 意思：最好是……；……再好不过
  - 接续：名詞・形容詞・動詞辞書形＋に越したことはない
  - 最好是……；……再好不过（这是常识性的最佳选择）
  - 后面常接「が」转折：安いに越したことはないが、品質も大事だ。
  - 一句话：常识性的最佳选择：〜に越したことはない（が…）。
  - 常错：あなたは早く寝るに越したことはないよ。（对个人建议） → あなたは早く寝たほうがいいよ。（个人建议用ほうがいい）
- 重点：〜てしかるべき
  - 意思：理应……；应当……
  - 接续：動詞て形＋しかるべきだ（しかるべき＋名詞）
  - 動詞て形＋しかるべきだ：理应……、本该……（现实却没有做到）
  - しかるべき＋名詞：适当的、相应的 —— しかるべき措置（适当的措施）、しかるべき人（合适的人）
  - 一句话：〜てしかるべきだ：理应（批评现状）；しかるべき＋名詞：适当的。
  - 常错：明日は雨がしかるべきだ。 → 明日は雨が降るだろう。（不是推测）

  - [c] 理想と現実が___いる。　选项：掛け離れて / 見越して / 請け負って / 織り込んで　答案：掛け離れて
  - [c] タイミングを___話を切り出した。　选项：見計らって / 差し控えて / 詰め寄って / 取りこぼして　答案：見計らって
