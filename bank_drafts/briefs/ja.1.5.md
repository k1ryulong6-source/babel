## 第 1 课（l = 1）：四字熟語・人の態度　题库已有 0 题
情境：先读一遍。四字熟语和拟声拟态词是日语里“中国人以为懂、其实最容易用错”的两块。
新词：一掃、一段落、帰属、決別、待望、延命、応対、細工、脱却、抵触、偏重、施工、加味、自負、加担
搭配 / 表达：優柔不断、傍若無人、厚顔無恥、付和雷同、自画自賛、我田引水
- 重点：〜ならでは
  - 意思：只有……才有的；……特有的
  - 接续：名詞＋ならではの＋名詞、名詞＋ならではだ
  - 最常见的形式：ＡならではのＢ（只有Ａ才有的Ｂ）；也可以放句末：Ａならではだ。
  - Ａ多是：地方、店、职业、人、季节 —— 京都ならではの景色、プロならではの技、手作りならではの温かさ。
  - 一句话：ＡならではのＢ：只有Ａ才有的（称赞）。
  - 常错：この町ならでは料理を食べた。 → この町ならではの料理を食べた。（修饰名词要加「の」）
  - 常错：新人ならではのミスが多い。 → 新人にありがちなミスが多い。（负面的“特有”不用ならでは）
- 重点：〜たるもの
  - 意思：身为……的人（就应当）
  - 接续：名詞＋たるもの（は）、〜べきだ・〜なければならない
  - 名詞＋たるもの（は），后面接〜べきだ・〜なければならない・〜てはならない。
  - 名词是身份、职责：教師・医者・政治家・リーダー・学生・男。
  - 一句话：身份＋たるもの、〜べきだ / 〜てはならない（身为……理应）。
  - 常错：学生たるもの、勉強が嫌いだ。 → 学生たるもの、勉強を怠ってはならない。（后项必须是“应该/不该”）
  - 常错：学生たるもの、私はこう思います。 → 学生として、私はこう思います。（单纯说身份用「として」）

  - [c] 仕事が___したら、お茶にしよう。　选项：一段落 / 一掃 / 待望 / 延命　答案：一段落
  - [c] 学歴___の社会を見直すべきだ。　选项：偏重 / 加担 / 細工 / 応対　答案：偏重

## 第 2 课（l = 2）：四字熟語・状況と変化　题库已有 0 题
情境：先读一遍。四字熟语和拟声拟态词是日语里“中国人以为懂、其实最容易用错”的两块。
新词：萎縮、敬遠、微動、拮抗、軟化、温存、介在、吐露、紛糾、逸脱、静観、対峙、陳謝、切望、阻害
搭配 / 表达：紆余曲折、一進一退、急転直下、右往左往、五里霧中、日進月歩
- 重点：〜を境に
  - 意思：以……为界；自……以后
  - 接续：名詞＋を境に（して・として）
  - 名詞＋を境に（して）：以……为界，（前后）发生了变化。
  - 名词多是时间点或事件：その日・事故・就任・結婚・三十歳。
  - 一句话：事件 / 时间点を境に + 变化（〜ようになった・一変した）。
  - 常错：三時を境に会議がある。 → 三時から会議がある。（后项没有变化，不用を境に）
- 重点：〜にとどまらず
  - 意思：不仅限于……
  - 接续：名詞・動詞辞書形＋にとどまらず
  - 名詞＋にとどまらず：不止于……（范围更大）。后面常接「〜にも・〜まで」＋及ぶ・広がる。
  - 也可以接动词辞书形：話題になるにとどまらず、社会現象になった。
  - 一句话：Ａにとどまらず、Ｂにも / まで（范围扩大）。
  - 常错：被害は一部の地域にとどまらなかった、全国に広がった。 → 被害は一部の地域にとどまらず、全国に広がった。（连接后句用「ず」形）

## 第 3 课（l = 3）：オノマトペ・気持ち　题库已有 0 题
情境：先读一遍。四字熟语和拟声拟态词是日语里“中国人以为懂、其实最容易用错”的两块。
新词：一様、豪快、低調、露骨、格段、丹念、皮肉、不気味、淡々、果敢、克明、絶妙、無難、端的、唐突
搭配 / 表达：もやもや、むしゃくしゃ、うんざり、げんなり、やきもき、ひやひや
- 重点：〜とも〜ともつかない
  - 意思：说不清是……还是……
  - 接续：名詞・普通形＋とも＋名詞・普通形＋ともつかない
  - ＡともＢともつかない＋名词：说不清是Ａ还是Ｂ。Ａ、Ｂ是名词或动词辞书形，常是一对相反或相近的东西：冗談・本気／喜び・悲しみ／賛成・反対。
  - 一句话：ＡともＢともつかない＋名词（说不清是Ａ还是Ｂ）。
  - 常错：賛成とも反対ともつく返事だった。 → 賛成とも反対ともつかない返事だった。（固定用否定「つかない」）
  - 常错：泣いているか笑っているかつかない顔。 → 泣いているとも笑っているともつかない顔。（要用「とも〜とも」）
- 重点：〜かと思いきや
  - 意思：原以为……没想到……
  - 接续：普通形（名詞・な形の「だ」は省略可）＋かと思いきや
  - 普通形＋かと思いきや：本以为……，没想到（结果相反）。
  - 后项是已经发生的意外事实，多用过去形。
  - 一句话：普通形＋かと思いきや + 意外的事实（预想落空）。
  - 常错：雨が降るかと思いきや、傘を持っていこう。 → 雨が降りそうだから、傘を持っていこう。（后项不能是意志）

  - [c] 前より___に上手になった。　选项：格段 / 淡々 / 低調 / 一様　答案：格段

## 第 4 课（l = 4）：オノマトペ・様子と動作　题库已有 0 题
情境：先读一遍。四字熟语和拟声拟态词是日语里“中国人以为懂、其实最容易用错”的两块。
新词：半端、不本意、弱気、性急、周到、粗末、如実、真摯、入念、煩雑、厄介、歴然、温厚、奇抜、理不尽
搭配 / 表达：てきぱき、もたもた、のらりくらり、しどろもどろ、ぎくしゃく、ちぐはぐ
- 重点：〜ずくめ
  - 意思：全是……；清一色……
  - 接续：名詞＋ずくめ
  - 名詞＋ずくめ：清一色都是……，全是……。能用的名词有限，最常见：黒ずくめ・いいことずくめ・規則ずくめ・ごちそうずくめ・異例ずくめ。
  - 一句话：黒ずくめ・いいことずくめ（整体全是一种）；错误满篇 → だらけ。
  - 常错：間違いずくめの答案だった。 → 間違いだらけの答案だった。（“到处是错”用だらけ）
  - 常错：汗ずくめになって働いた。 → 汗まみれになって働いた。（沾满液体用まみれ）
- 重点：〜めく
  - 意思：带有……的气息；有……的样子
  - 接续：名詞＋めく（めいた＋名詞）
  - 名詞＋めく：带有……的样子、气息。最常见：春めく・秋めく・冗談めく・謎めく・皮肉めく・言い訳めく。
  - 活用和五段动词一样：めいて（きた）、修饰名词多用めいた：謎めいた人物、冗談めいた口調。
  - 一句话：春めいてきた・謎めいた〜（带有……的气息；按五段变形）。
  - 常错：だんだん春めきた。 → だんだん春めいてきた。（五段活用：めく→めいて）
  - 常错：言い訳めく話はやめて。 → 言い訳めいた話はやめて。（修饰名词用「めいた」）

## 第 5 课（l = 5）：オノマトペ・体と感覚　题库已有 0 题
情境：先读一遍。四字熟语和拟声拟态词是日语里“中国人以为懂、其实最容易用错”的两块。
新词：尋常、物騒、厳正、雑多、親身、整然、非凡、律儀、潤沢、執拗、陳腐、聡明、稚拙、気さく、生半可
搭配 / 表达：ぐったり、へとへと、ずきずき、ひりひり、げっそり、くたくた
- 重点：〜極まりない
  - 意思：极其……；……之至
  - 接续：な形容詞語幹＋極まりない（極まる）
  - な形容词词干＋極まりない（＝極まる）：极其……，……到了极点。
  - 常见：失礼・危険・迷惑・不愉快・残念・無礼・退屈極まりない —— 多是负面评价。
  - 一句话：な形容词词干＋極まりない（极其……，多负面）。
  - 常错：危険な極まりない運転だ。 → 危険極まりない運転だ。（词干直接接，不加な）
  - 常错：失礼の極まりない態度だ。 → 失礼極まりない態度だ。（不加の）
- 重点：〜の極み
  - 意思：……之极；极其……
  - 接续：名詞＋の極み
  - 名詞＋の極み：……之极、……的顶点。
  - 常见：光栄の極み・感激の極み・贅沢の極み・幸せの極み・痛恨の極み・疲労の極み。
  - 一句话：名詞＋の極み：光栄の極み・贅沢の極み（……之至）。
  - 常错：光栄極みです。 → 光栄の極みです。（名词后要加「の」）
  - 常错：光栄極まりないです。（致辞） → 光栄の極みです。（致辞、感激用の極み）
