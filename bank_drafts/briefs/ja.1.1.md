## 第 1 课（l = 1）：事件と捜査　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面逐个讲这些新闻用语，重点会讲透。
新词：検挙、押収、送検、黙秘、示談、謹慎、失脚、罷免、逝去、安否、容態、捏造、着服、暴露、露見
搭配 / 表达：足がつく、口を割る、尻尾を出す、泥を被る
- 重点：中日同形异义：検挙・暴露・逝去
  - 这几个词中文里也有，但意思或方向不同，是 N1 以上最容易“看懂了却用错”的一类：
  - 検挙（けんきょ）：警方查处、拘捕。中文“检举”是群众揭发。
  - 暴露（ばくろ）：揭发他人的秘密、坏事（他動詞的に使う）。中文“暴露”多是自己不小心显露。
  - 逝去（せいきょ）：对他人之死的敬称，不用于自己家人。
  - 一句话：先问“谁对谁”：検挙＝警方，暴露＝揭别人，逝去＝敬称他人。
  - 常错：市民が不正を検挙した。 → 市民が不正を告発した。（検挙的主语是警方）
  - 常错：うっかり本音を暴露してしまった。 → うっかり本音が出てしまった／本音を漏らしてしまった。（暴露多指揭发别人）
- 重点：〜をもって：郑重宣告“到此为止 / 由此开始”
  - 名詞＋をもって（更郑重：をもちまして）
  - ① 时间的界限：本日をもって閉店いたします（今天为止）
  - ② 手段・凭借（书面）：書面をもって通知する（以书面形式）
  - 一句话：公告式的“到此为止”＝〜をもって（〜をもちまして）；日常用「で」。
  - 常错：昨日をもって友達とご飯を食べた。 → 昨日、友達とご飯を食べた。（日常小事不用「をもって」）
  - 常错：本日でもって閉店します。 → 本日をもって閉店します。（助词是「を」）
- 重点：〜に即して：结合实际 / 依照事实
  - 名詞＋に即して（修饰名词：に即した＋名詞）
  - 对象多是事実・実態・現実・実情・状況：按照真实情况来判断、制定。
  - 一句话：実態・事実に即して；法律・ルールに則って。
  - 常错：規則に即して処分した。 → 規則に則って処分した。（规则用「則って」）
  - 常错：実態に則した支援 → 実態に即した支援（实际情况用「即した」）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 「足がつく」の意味は？　选项：歩き始める / 犯人の身元や逃げた先がわかる / 仕事を辞める / 足が疲れる　答案：犯人の身元や逃げた先がわかる
  - [o] 容疑者がついに口を割った
  - [tr] 嫌疑人始终保持沉默。 → 容疑者は一貫して黙秘している。

## 第 2 课（l = 2）：政治と行政　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面逐个讲这些新闻用语，重点会讲透。
新词：立案、参画、提起、明言、言明、善処、却下、順延、一元化、打診、遂行、断行、推奨、喚起、啓発
搭配 / 表达：物議を醸す、首を突っ込む、槍玉に挙げる、一翼を担う
- 重点：官方用语的分寸：善処・明言を避ける・打診
  - 善処します：字面“妥善处理”，政治、商务场合常是不作承诺的推脱。
  - 明言を避ける：回避明确表态；明言する：明确表态。（「言明」意思相同，更书面）
  - 打診する：事先试探对方意向（人事、合作）；参画する：从规划阶段参与（比「参加」更深）。
  - 一句话：善処＝不承诺；明言を避ける＝不表态；打診＝探口风；参画＝从规划起参与。
  - 常错：医者に打診してもらった。 → 医者に診察してもらった。（「打診」在医学上虽也有“叩诊”义，但新闻里是“试探意向”）
  - 常错：彼は会議に参画した。（只是出席） → 彼は会議に参加した／出席した。（参画＝从规划阶段深度参与）
- 重点：〜に鑑みて と 〜を踏まえて
  - 名詞＋に鑑みて／に鑑み：鉴于（某个重大情况），所以采取措施。
  - 名詞＋を踏まえて／を踏まえ：以……为前提、基础，在此之上考虑下一步。
  - 一句话：严重事态に鑑みて（所以…）；结果、意见を踏まえて（在此基础上…）。
  - 常错：前回の議論に鑑みて、次の案を出す。 → 前回の議論を踏まえて、次の案を出す。（讨论结果是“基础”，用踏まえ）
  - 常错：状況を鑑みて → 状況に鑑みて（规范用法是「に」）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 雨天のため、試合は翌日に___となった。　选项：却下 / 順延 / 遂行 / 提起　答案：順延
  - [o] 新制度は早くも物議を醸している

## 第 3 课（l = 3）：社会問題　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面逐个讲这些新闻用语，重点会讲透。
新词：憂慮、危惧、警鐘、喫緊、急務、逼迫、疲弊、閉塞、蔓延、横行、頻発、山積、淘汰、趨勢、余波
搭配 / 表达：歯止めをかける、拍車を掛ける、火に油を注ぐ、波紋を呼ぶ
- 重点：坏事扩散：蔓延・横行・頻発
  - 蔓延（まんえん）：病、风气像藤蔓一样扩散开 —— 感染が蔓延する、不信感が蔓延する
  - 横行（おうこう）：坏事公然到处发生、无人管 —— 不正が横行する、詐欺が横行する
  - 頻発（ひんぱつ）：事件、事故频繁发生 —— 事故が頻発する、地震が頻発する
  - 一句话：面在扩大＝蔓延；肆无忌惮＝横行；次数多＝頻発。
  - 常错：この道では事故が蔓延している。 → この道では事故が頻発している。（事故是“次数”，用頻発）
  - 常错：この店では毎日小さなミスが横行している。 → この店では毎日小さなミスが起きている。（横行 指违法、不正之事公然泛滥，日常小失误不用）
- 重点：〜の一途をたどる：一直往一个方向（多为变坏）
  - 名詞（増加・減少・悪化・拡大）＋の一途をたどる
  - 表示趋势只朝一个方向持续发展，没有回头的迹象。
  - 一句话：増加・減少・悪化・拡大＋の一途をたどる：有增无减、每况愈下。
  - 常错：物価が高くなるの一途をたどっている。 → 物価は上昇の一途をたどっている。（前面接变化名词）
  - 常错：景気は回復と悪化の一途をたどる。 → 景気は悪化の一途をたどる。（只能是一个方向）
- 重点：〜を余儀なくされる／させる：被迫 —— 看清谁是主语
  - 漢語名詞＋を余儀なくされる：（主语）被迫……
  - 原因＋が＋人・組織に＋〜を余儀なくさせる：（原因）迫使……
  - 一句话：受影响的一方 〜を余儀なくされる；原因作主语 〜を余儀なくさせる。
  - 常错：台風がイベントの中止を余儀なくされた。 → 台風がイベントの中止を余儀なくさせた。／イベントは台風で中止を余儀なくされた。（主语是原因时用させる）
  - 常错：彼は帰国するを余儀なくされた。 → 彼は帰国を余儀なくされた。（前面接名词）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 「淘汰」の読み方は？　选项：とうた / とおた / どうた / とうだ　答案：とうた
  - [c] 「歯止めをかける」の意味は？　选项：物事の進行を食い止める / 歯の治療をする / 急いで止まる / 口を閉じる　答案：物事の進行を食い止める
  - [o] 少子化に歯止めをかける必要がある

## 第 4 课（l = 4）：報道の言い回し　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面逐个讲这些新闻用语，重点会讲透。
新词：浮上、再燃、終息、収束、炎上、鈍化、失速、暗転、下火、席巻、猛威、散見、示唆、酷似、突出
搭配 / 表达：一石を投じる、口火を切る、軌道に乗る、暗礁に乗り上げる
- 重点：収束 と 終息：平息 vs 彻底结束
  - 収束（しゅうそく）：混乱的局面被控制住、平息下来 —— 事態が収束する、騒動を収束させる（可以作他动词）
  - 終息（しゅうそく）：疫病、战乱等彻底结束 —— 感染が終息する、内戦が終息する（基本只作自动词）
  - 一句话：控制住了＝収束（可以“収束させる”）；彻底完了＝終息。
  - 常错：会社は感染を終息させた。 → 会社は事態を収束させた。（人为平息局面用収束させる）
  - 常错：戦争が収束宣言された。 → 戦争の終息が宣言された。（彻底结束用終息）
- 重点：〜を皮切りに：以……为开端，接连展开
  - 名詞＋を皮切りに（して／として）
  - 以某件事为第一个，后面同类的事接连发生或展开。
  - 一句话：Aを皮切りに、B、C、D…が次々と。
  - 常错：朝ご飯を皮切りに、会社へ行った。 → 朝ご飯を食べてから、会社へ行った。（日常先后顺序不用）
  - 常错：この映画を皮切りに、彼は引退した。 → この映画を最後に、彼は引退した。（皮切り是“开端”；“以…为最后”用「を最後に」）
- 重点：〜に至っては：至于……（举出最极端的例子）
  - 名詞＋に至っては
  - 先说一般情况，再拿出最极端的一个例子：“其他都这样了，至于X，竟然……”。
  - 一句话：一般情况 → Xに至っては → 最极端的结果。
  - 常错：次に、天気に至っては晴れです。 → 次に、天気についてですが、晴れです。（中性换话题不用）
  - 常错：Bさんに至っても反対している。 → Bさんに至っては反対している。（固定形式是「に至っては」）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 景気回復のペースが___している。　选项：鈍化 / 浮上 / 示唆 / 突出　答案：鈍化
  - [c] 新たな疑惑が___した。　选项：浮上 / 下火 / 収束 / 酷似　答案：浮上
  - [c] 「暗礁に乗り上げる」の意味は？　选项：船が沈む / 思わぬ障害で物事が進まなくなる / 危険を冒す / 新しく始める　答案：思わぬ障害で物事が進まなくなる

## 第 5 课（l = 5）：論説の副詞　题库已有 0 题
情境：先读一遍，不用每个词都懂。下面逐个讲这些新闻用语，重点会讲透。
新词：概して、一概に、往々、甚だ、殊に、専ら、至って、断じて、延いては、取り分け、否応なく、図らずも、期せずして、遠からず、辛うじて
搭配 / 表达：一朝一夕、前代未聞、本末転倒、賛否両論
- 重点：和否定呼应的副词：一概に・断じて
  - 一概に〜ない：不能一概而论 —— 一概に悪いとは言えない
  - 断じて〜ない：绝对不 —— 断じて許されない
  - 这类副词后面必须接否定（或否定意味的表达），单独用就是错。
  - 一句话：一概に〜とは言えない；断じて〜ない；肯定的“断然”＝断固として。
  - 常错：一概に正しい。 → 一概に正しいとは言えない。（一概に 后面要接否定）
  - 常错：断じて賛成する。 → 断固として賛成する。／断じて反対だ。（断じて 接否定）
- 重点：〜にほかならない：正是……，不是别的
  - 名詞＋にほかならない：正是……
  - 〜からにほかならない：正是因为……
  - 一句话：结论 〜にほかならない；原因 〜からにほかならない。
  - 常错：成功したのは、努力したにほかならない。 → 成功したのは、努力したからにほかならない。（表原因要加から）
  - 常错：これは失敗のほかならない。 → これは失敗にほかならない。（助词是「に」）
- 重点：〜は否めない：不可否认（承认负面的事实）
  - 名詞＋は否めない／〜（の）は否めない／常见：〜感は否めない、〜事実は否めない
  - 一句话：〜は否めない＝不得不承认（负面）；正面用「〜は確かだ」。
  - 常错：彼が優秀なのは否めない。 → 彼が優秀なのは間違いない。（正面内容用“間違いない・確かだ”）
  - 常错：準備不足を否めない。 → 準備不足は否めない。（助词用「は」）

  - [o] 語学は一朝一夕には身につかない
