单元目标：尊敬语・谦让语・郑重语、商务书信惯用语、书面文型

## 第 1 课（l = 1）：尊敬語と謙譲語　题库已有 0 题
情境：先读一遍。敬语和书面套语是“写对了没人夸、写错了马上露馅”的部分，这一单元重点练准确。
新词：承る、拝読、恐縮、足労、芳名、各位、健勝、自愛、愛顧、鞭撻、教示、失念、目下、一報、平素
搭配 / 表达：いらっしゃる、召し上がる、伺う、申し上げる
- 重点：尊敬语还是谦让语：先看动作是谁做的
  - 尊敬语：对方（上级、客户）的动作 → 抬高：いらっしゃる・おっしゃる・召し上がる・ご覧になる・お〜になる。
  - 谦让语：自己（或自己这边的人）的动作 → 压低：伺う・申し上げる・拝見する・承る・お〜する／いたす。
  - 郑重语：只对听话人客气：です・ます・ございます・参る・申す。
  - 一句话：对方做 → 尊敬语，自己做 → 谦让语；不叠加，不把谦让语给对方。
  - 常错：こちらの資料を拝見してください。 → こちらの資料をご覧ください。（让对方看，用尊敬语）
  - 常错：社長がおっしゃられました。 → 社長がおっしゃいました。（二重敬语）
- 重点：〜におかれましては
  - 意思：（对方）……方面；……您
  - 接续：人物名詞＋におかれましては
  - 几乎只出现在书信、致辞开头的问候，整句当模板记：〜におかれましては、ますますご清栄（ご健勝）のこととお慶び申し上げます。
  - 一句话：对方＋におかれましては、ますますご〜のこととお慶び申し上げます。
  - 常错：私におかれましては、元気に過ごしております。 → 私は元気に過ごしております。（不能用于自己）
- 重点：〜賜りますようお願い申し上げます
  - 意思：敬请……
  - 接续：ご＋名詞（ご指導・ご支援・ご愛顧）＋を賜りますよう
  - 常用搭配：ご指導ご鞭撻・ご愛顧・ご支援・ご理解・ご高配を賜りますよう、お願い申し上げます。
  - 一句话：ご＋名詞を賜りますよう、お願い申し上げます（书信结尾，敬请……）。
  - 常错：ご指導ご鞭撻を賜りますようお願いします。 → ご指導ご鞭撻を賜りますよう、お願い申し上げます。（前后语体要一致，用申し上げます）
已有题目示例（不要重复，也不要只换几个词）：

  - [o] ご注文を確かに承りました

## 第 2 课（l = 2）：ビジネスメール　题库已有 0 题
情境：先读一遍。敬语和书面套语是“写对了没人夸、写错了马上露馅”的部分，这一单元重点练准确。
新词：取り急ぎ、追って、かねがね、先般、諸般、別途、適宜、随時、逐一、他言、不躾、僭越、忌憚、所存、内密
搭配 / 表达：お手数をおかけしますが、恐れ入りますが、差し支えなければ、ご確認のほどよろしくお願いいたします
- 重点：〜いただければ幸いです
  - 意思：如蒙……将不胜荣幸；烦请……
  - 接续：動詞て形・ご＋名詞＋いただければ幸いです（幸甚に存じます）
  - 最常见搭配：ご確認・ご検討・ご返信・ご協力いただければ幸いです；更郑重：幸甚に存じます。
  - 一句话：ご＋名詞いただければ幸いです（烦请……，邮件请求）。
  - 常错：ご確認してくだされば幸いです。 → ご確認いただければ幸いです。（用「いただければ」，不用「ご〜して」）
  - 常错：（对客户）資料を確認してください。 → 資料をご確認いただければ幸いです。（对客户别用「〜てください」）
- 重点：取り急ぎ〜まで
  - 意思：先匆匆……（简要告知、致意）
  - 接续：取り急ぎ＋名詞（ご連絡・お礼・ご報告）＋まで
  - 固定在邮件最后一句：取り急ぎご連絡・ご報告・お礼・ご確認まで。
  - 一句话：取り急ぎ＋ご連絡・ご報告・お礼＋まで。（邮件最后一句；道歉不用）
  - 常错：取り急ぎお詫びまで。 → まずは略儀ながら、書中にてお詫び申し上げます。（道歉不说“匆忙”）
  - 常错：取り急ぎご報告までです。 → 取り急ぎご報告まで。（まで后面不加です）

  - [c] お噂は___伺っております。　选项：かねがね / 取り急ぎ / 別途 / 適宜　答案：かねがね
  - [c] ___ながら、私から一言申し上げます。　选项：僭越 / 忌憚 / 内密 / 諸般　答案：僭越

## 第 3 课（l = 3）：依頼と断り　题库已有 0 题
情境：先读一遍。敬语和书面套语是“写对了没人夸、写错了马上露馅”的部分，这一单元重点练准确。
新词：割愛、留意、合点、一睡、長居、閉口、失笑、熟慮、一喝、一笑、吟味、一蹴、進呈、推察、添削
搭配 / 表达：生憎、せっかくですが、見送らせていただきます、検討させていただきます
- 重点：〜いたしかねます
  - 意思：难以……（礼貌拒绝）
  - 接续：ご・お＋動詞ます形・漢語名詞＋いたしかねます
  - 「〜かねる」（难以……）＋谦让语「いたす」。服务业、客服的标准拒绝：お答えいたしかねます・お受けいたしかねます・わかりかねます。
  - 一句话：お＋ます形＋いたしかねます（恕难……，礼貌拒绝）。
  - 常错：ご質問にはお答えできかねません。 → ご質問にはお答えいたしかねます。（かねる 本身就是否定，不再加否定）
  - 常错：その件はいたしかねないです。 → その件はいたしかねます。（かねない 是“有可能”）
- 重点：〜かと存じます
  - 意思：我认为……（谦逊）
  - 接续：普通形（名詞・な形の「だ」は省略）＋かと存じます
  - 「〜と思います」的谦逊形；「か」让判断变得不那么断定：〜がよろしいかと存じます・〜は難しいかと存じます。
  - 一句话：普通形（去だ）＋かと存じます（委婉地说自己的意见）。
  - 常错：こちらがよろしいだかと存じます。 → こちらがよろしいかと存じます。（不加「だ」）
  - 常错：妥当だかと存じます。 → 妥当かと存じます。（な形容词去掉だ）

  - [f] ___ですが、その日は予定が入っております。(不巧)　答案：あいにく

## 第 4 课（l = 4）：書き言葉の文型　题库已有 0 题
情境：先读一遍。敬语和书面套语是“写对了没人夸、写错了马上露馅”的部分，这一单元重点练准确。
新词：鑑みる、顧みる、省みる、遡る、赴く、臨む、志す、極める、重んじる、軽んじる、担う、見据える、見出す、育む、もたらす
搭配 / 表达：異口同音、首尾一貫、公明正大、大義名分
- 重点：〜に照らして
  - 意思：对照……；依照……
  - 接续：名詞＋に照らして（に照らし合わせて）
  - 常见：法律・規則・常識・経験・事実・社会通念に照らして（判断する・考える）。
  - 一句话：基准に照らして + 判断、评价（拿标准衡量）。
  - 常错：会議は規則に照らして進められた。 → 会議は規則に則って進められた。（“按规则做事”用に則って）
- 重点：〜に則って
  - 意思：依照……；遵循……
  - 接续：名詞＋に則って（に則った＋名詞）
  - 读音是 のっとって（常读错）。常见：規則・法律・伝統・先例・ルール・手順に則って（行う・進める）；修饰名词：に則った手続き。
  - 一句话：規則・伝統に則って + 做事（正式的“遵照”；读のっとって）。
  - 常错：説明書に則って、おもちゃを組み立てた。 → 説明書に従って、おもちゃを組み立てた。（日常小事用に従って）
  - 常错：規則にそくって行う。 → 規則にのっとって行う。（读音是のっとって）

## 第 5 课（l = 5）：学期総復習　题库已有 0 题
情境：先读一遍。敬语和书面套语是“写对了没人夸、写错了马上露馅”的部分，这一单元重点练准确。
新词：醍醐味、冥利、造詣、素養、見識、知見、洞察、機微、極意、王道、鉄則、本領、境地、佳境、本望
搭配 / 表达：一期一会、温故知新、切磋琢磨、有言実行
- 重点：〜をおいて
  - 意思：除了……以外（没有）
  - 接续：名詞＋をおいて（ほかに）〜ない
  - 固定形：Ａをおいて（ほかに）〜ない：除了Ａ，没有别的。
  - 一句话：Ａをおいてほかに〜ない（非Ａ莫属，称赞）。
  - 常错：彼をおいて、みんな遅刻した。 → 彼以外、みんな遅刻した。（普通的排除用「以外」）
  - 常错：この仕事ができるのは彼をおいている。 → この仕事ができるのは彼をおいてほかにいない。（后面必须接否定）
- 重点：〜に足る
  - 意思：值得……；足以……
  - 接续：名詞（サ変）・動詞辞書形＋に足る（に足りない）
  - 名詞・動詞辞書形＋に足る＋名词：值得……的、足以……的。常见：信頼に足る・尊敬に足る・満足に足る・語るに足る。
  - 否定固定说：取るに足りない（不值一提）。
  - 一句话：信頼に足る〜・取るに足りない（值得 / 不值一提）。
  - 常错：彼は信頼するに足りる人物だ。（书面评价） → 彼は信頼に足る人物だ。（书面评价用「足る」）
  - 常错：取るに足らなくない問題だ。 → 決して取るに足りない問題ではない。（否定要整体否定）
