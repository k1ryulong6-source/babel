# 单元简报：en.1.7 修饰与连接

单元目标：形容词副词与比较、介词、连词、情态动词
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：形容词与副词　题库已有 0 题
情境：interesting 和 interested、well 和 good、hard 和 hardly —— 形容词和副词里最容易错的几对。
新词：effort、decide、rate、strong、possible、heart、drug、leader、light、voice、wife、whole
搭配 / 表达：be interested in、be good at、be afraid of
- 重点：-ing 和 -ed 形容词：interesting 还是 interested
  - -ing：事物本身给人的感觉 —— The story is interesting / boring / surprising.
  - -ed：人的感受 —— I'm interested / bored / surprised / tired / excited.
  - 一对一对记：interesting / interested，boring / bored，exciting / excited，tiring / tired，confusing / confused
  - 一句话：事物 -ing，人的感受 -ed。
  - 常错：I'm boring.（想说“我很无聊”） → I'm bored.（人的感受用 -ed）
  - 常错：I'm interesting in music. → I'm interested in music.（）
- 重点：good / well，hard / hardly，late / lately
  - good 是形容词，well 是副词：She is a good singer. / She sings well.（well 作形容词时指“身体好”：I'm well.）
  - hard 既是形容词也是副词：He works hard.　hardly 是“几乎不”：I can hardly hear you.
  - late 晚（副词也是 late）：He arrived late.　lately 是“最近”。
  - 一句话：good 形 / well 副；hard 努力 / hardly 几乎不；late 晚 / lately 最近。
  - 常错：She sings good. → She sings well.（修饰动词用 well）
  - 常错：He works hardly.（想说努力） → He works hard.（hardly = 几乎不）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] I'm good ___ math.　答案：at
  - [o] I am interested in history.
  - [tr] 我很擅长数学。 → I'm good at math.

## 第 2 课（l = 2）：比较级与最高级　题库已有 0 题
情境：cheaper、better、the best、the most expensive、as cheap as：比较的三种说法。
新词：police、mind、finally、pull、return、free、military、price、less、decision、explain、son
搭配 / 表达：more and more、as … as possible、the same as
- 重点：比较级和最高级：怎么变
  - 短词（一个音节，及 -y 结尾的两音节词）加 -er / -est：tall → taller → the tallest；big → bigger → the biggest；easy → easier → the easiest
  - 长词（两个音节以上）用 more / most：expensive → more expensive → the most expensive
  - 不规则：good / well → better → best；bad → worse → worst；many / much → more → most；little → less → least；far → farther / further
  - 最高级前一般加 the，后面常跟 in / of 表示范围：the best in the shop
  - 一句话：短词 -er/-est，长词 more/most；good → better → best，bad → worse → worst。
  - 常错：more cheaper → cheaper（不能双重比较）
  - 常错：expensiver → more expensive（长词用 more）
- 重点：as … as：和……一样
  - as + 原级 + as：和……一样 —— He is as tall as his brother.
  - 否定：not as … as = 不如 —— This phone is not as cheap as that one.
  - as soon as possible 尽快；the same as 和……一样
  - 一句话：as + 原级 + as；not as … as = 不如。
  - 常错：as taller as → as tall as（中间用原级）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] More and more people work from home.
  - [tr] 越来越多的人在家工作。 → More and more people work from home.

## 第 3 课（l = 3）：介词：时间与地点　题库已有 0 题
情境：on the bus、at the station、at seven、in the café、on the second floor：介词选错，是中国学生英语里最多的小错误。
新词：hope、develop、view、relationship、carry、town、road、drive、arm、true、federal、break
搭配 / 表达：in the end、on the way、at the same time
- 重点：时间：at 点，on 天，in 段
  - at + 时刻、点：at 7, at noon, at night, at the weekend（英式）
  - on + 某一天：on Monday, on May 5th, on my birthday, on Monday morning
  - in + 一段：in July, in 2025, in summer, in the morning, in the 1990s
  - 不加介词：today, tomorrow, yesterday, this / next / last week
  - 一句话：at 点、on 天、in 段；next / last / this 前不加介词。
  - 常错：in Monday → on Monday（）
  - 常错：on next week → next week（next / last / this 前不加介词）
- 重点：地点和交通：at 点、on 面、in 里
  - at + 一个点（看作位置）：at the station, at home, at the door
  - on + 表面、楼层、街道：on the table, on the wall, on the second floor, on Main Street
  - in + 空间内、城市国家：in the box, in the café, in Tokyo
  - 交通：on a bus / train / plane（能站着走动的）；in a car / taxi（只能坐着）；by bus（方式）
  - 一句话：点 at、面 on、里 in；bus / train on，car / taxi in。
  - 常错：I'm in the bus. → I'm on the bus.（）
  - 常错：on the taxi → in the taxi（）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] I am on the way.
  - [tr] 我们住在二楼。 → We live on the second floor.

## 第 4 课（l = 4）：连词：and / but / so / because　题库已有 0 题
情境：because、because of、so、but：连接句子的小词，中国学生最常犯的错是“两个连词一起用”。
新词：difference、receive、value、international、building、action、full、model、join、season、society、tax
搭配 / 表达：because of、not only … but also、as well
- 重点：because 和 so 不能一起用；although 和 but 也不能
  - 英语一个句子里只用一个连词连接两个分句：
  - Because it rained, we stayed home. ✓ 或 It rained, so we stayed home. ✓ —— 但不能 Because it rained, so we stayed home.
  - Although it was late, he kept working. ✓ 或 It was late, but he kept working. ✓ —— 但不能 Although…, but…
  - 一句话：因为……所以……、虽然……但是……：英语只留一个。
  - 常错：Because I was sick, so I stayed home. → Because I was sick, I stayed home.（去掉 so）
  - 常错：Although it was late, but he worked. → Although it was late, he worked.（去掉 but）
- 重点：because + 句子，because of + 名词
  - because 后面接完整的句子（有主语和谓语）：because it snowed
  - because of 后面接名词：because of the snow
  - 同理：although + 句子 / despite + 名词
  - 一句话：because + 句子；because of + 名词。
  - 常错：because of it snowed → because it snowed（）
  - 常错：because the snow → because of the snow（）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] She is not only smart but also kind.
  - [tr] 她不但聪明而且善良。 → She is not only smart but also kind.

## 第 5 课（l = 5）：情态动词　题库已有 0 题
情境：could、mustn't、have to、don't have to、had better：同样是“要不要”，语气差别很大。
新词：director、position、player、agree、especially、record、pick、wear、paper、special、space、ground
搭配 / 表达：Could you …?、have to、had better
- 重点：情态动词 + 动词原形
  - 情态动词（can, could, may, might, must, should, will, would）后面一律接动词原形，而且没有三单变化：She can swim.（不是 cans / can swims）
  - 否定直接加 not：can't, shouldn't, mustn't；疑问把情态动词提前：Can you…? Should I…?
  - 一句话：情态动词 + 原形，不加 to、不加 s。
  - 常错：She can speaks English. → She can speak English.（）
  - 常错：You should to go. → You should go.（）
- 重点：mustn't（禁止）和 don't have to（不必）
  - must：必须（说话人认为）　have to：不得不（客观规定）
  - mustn't = 禁止：You mustn't smoke here.
  - don't have to = 不必（可以做，但没必要）：You don't have to come early.
  - had better + 原形 = 最好（否则有不好的后果）：You'd better hurry.
  - 一句话：mustn't 不许，don't have to 不用；had better + 原形。
  - 常错：You mustn't come tomorrow.（想说“不用来”） → You don't have to come tomorrow.（mustn't = 禁止）
  - 常错：You had better to go. → You had better go.（）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Could you open the window?
