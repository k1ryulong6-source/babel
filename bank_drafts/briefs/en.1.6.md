# 单元简报：en.1.6 过去与将来

单元目标：一般过去时、将来时、现在完成时入门
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：一般过去时：was / were 与规则动词　题库已有 0 题
情境：watched、studied、was、were、did：说过去的事，动词要变。
新词：policy、everything、love、process、music、including、consider、appear、actually、buy、probably、human
搭配 / 表达：… ago、last night、stay up late
- 重点：一般过去时：过去某个时间，已经结束
  - 说过去某个时间发生、已经结束的事：yesterday, last night, two years ago, in 2019, when I was a child
  - be：I / he / she / it → was；you / we / they → were
  - 规则动词加 -ed：work → worked，live → lived，study → studied，stop → stopped
  - 否定和疑问借 did，动词回原形：I didn't go. Did you see it?
  - 一句话：过去时间 → 动词过去式；did 一出现，动词回原形。
  - 常错：I go there yesterday. → I went there yesterday.（有过去时间，动词要变）
  - 常错：Did you went? → Did you go?（did 之后用原形）
- 重点：-ed 的三种读法：/t/、/d/、/ɪd/
  - 清辅音（p k f s sh ch）后读 /t/：worked, stopped, watched
  - 浊辅音和元音后读 /d/：played, lived, called
  - t / d 后读 /ɪd/，多一个音节：wanted, needed, started
  - 一句话：只有 t / d 后面的 -ed 才多一个音节。
  - 常错：worked 读成 /ˈwɜːkɪd/ → worked /wɜːkt/（只有 t/d 后才加音节）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] stop 的过去式是？　选项：stoped / stopped / stopt / stopd　答案：stopped
  - [f] I ___ (stay) up late last night.　答案：stayed
  - [o] I moved here two years ago.

## 第 2 课（l = 2）：不规则动词的过去式　题库已有 0 题
情境：met、made、took、left —— 最常用的动词，偏偏是不规则的。
新词：wait、serve、market、die、send、expect、sense、build、stay、fall、nation、plan
搭配 / 表达：have a good time、make a mistake、take a break
- 重点：不规则动词：成组记，比一个个背快
  - -ought / -aught：buy → bought，bring → brought，think → thought，teach → taught，catch → caught
  - i → a：begin → began，drink → drank，sing → sang，swim → swam
  - ee / ea → e + t：keep → kept，sleep → slept，feel → felt，meet → met，leave → left
  - 不变：put, cut, hit, let, set, cost, shut
  - 完全不规则：go → went，be → was/were，have → had，do → did，make → made，take → took，see → saw，say → said，get → got
  - 一句话：成组记：-ought、i→a、ee→e+t、不变。
  - 常错：buyed → bought（）
  - 常错：thinked → thought（）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] We ___ a great time last weekend.　选项：have / had / has / haved　答案：had
  - [c] She ___ me the news yesterday.　选项：tell / told / telled / tells　答案：told
  - [f] I ___ (make) a big mistake.　答案：made

## 第 3 课（l = 3）：将来时：will 与 be going to　题库已有 0 题
情境：will 和 be going to 都说将来，但不能随便换。
新词：cut、college、interest、death、course、experience、behind、reach、local、kill、remain、effect
搭配 / 表达：next week、call back、as soon as
- 重点：will 还是 be going to
  - be going to + 原形：说话前已经打算好的事；眼前有迹象的预测
  - I'm going to visit Paris next month.（早就计划好了）　Look at the clouds — it's going to rain.
  - will + 原形：说话时临时决定；承诺、提议；一般的预测
  - The phone's ringing. — I'll get it.（刚决定）　I'll help you.　I think it will be fine.
  - 一句话：早有打算 → going to；刚刚决定、承诺 → will。
  - 常错：The phone is ringing. — I'm going to get it. → I'll get it.（临时决定用 will）
  - 常错：I will visit my parents next week, I booked the tickets already. → I'm going to visit my parents next week.（已有计划用 going to）
- 重点：when / if / as soon as 从句：用现在时表示将来
  - 时间和条件从句里，用一般现在时代替将来时：
  - I'll call you when I get home.（不说 when I will get）
  - If it rains tomorrow, we'll stay home.
  - I'll tell you as soon as I know.
  - 一句话：主句 will，从句（when / if / as soon as）用现在时。
  - 常错：I'll call you when I will get home. → I'll call you when I get home.（）
  - 常错：If it will rain, … → If it rains, …（）
已有题目示例（不要重复，也不要只换几个词）：
  - [f] I'll call you ___. (回电话)　答案：back
  - [o] I'll tell you as soon as I know.

## 第 4 课（l = 4）：现在完成时入门　题库已有 0 题
情境：I've been、I went、I've lived —— 现在完成时和一般过去时，这一课讲清楚它们的分工。
新词：yeah、suggest、class、control、raise、care、perhaps、late、hard、field、else、pass
搭配 / 表达：so far、for a long time、have been to
- 重点：现在完成时 vs 一般过去时
  - 一般过去时：说过去某个具体时间的事 —— I went there last spring.
  - 现在完成时 have / has + 过去分词：不提具体时间，关心和现在的关系：
  - ① 经历（到现在为止有没有）：Have you ever been to Kyoto?
  - ② 持续到现在：I've lived here for three years.
  - ③ 结果影响现在：I've lost my key.（现在还找不到）
  - 一句话：有具体过去时间 → 过去时；到现在为止 → 现在完成时。
  - 常错：I have seen that movie last week. → I saw that movie last week.（有具体过去时间）
  - 常错：I live here since 2020. → I have lived here since 2020.（持续到现在）
- 重点：for 和 since；been 和 gone
  - for + 一段时间：for three years, for a long time
  - since + 起点：since 2020, since last May, since I was a child
  - has been to：去过（已经回来）；has gone to：去了（人还在那里）
  - 一句话：for + 时长，since + 起点；been to 去过，gone to 去了。
  - 常错：since three years → for three years（）
  - 常错：He has been to Beijing. He's still there. → He has gone to Beijing.（）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] Have you ever been to Kyoto?
  - [tr] 我在这里住了十年了。 → I've lived here for ten years.

## 第 5 课（l = 5）：时态对比复习　题库已有 0 题
新词：former、sell、major、sometimes、require、along、development、themselves、report、role、better、economic
搭配 / 表达：these days、used to、from now on
- 重点：用时间词选时态：五个时态放在一起
  - every day / usually / often → 一般现在：I work in Osaka.
  - now / at the moment / Look! → 现在进行：I'm working now.
  - yesterday / last … / … ago / in 2019 → 一般过去：I worked late yesterday.
  - ever / never / already / yet / for / since → 现在完成：I've worked here for two years.
  - tomorrow / next … / soon → 将来：I'll work from home tomorrow.
  - 一句话：先圈时间词，再选时态。
  - 常错：I have lost my keys yesterday. → I lost my keys yesterday.（yesterday → 过去时）
  - 常错：We know each other since childhood. → We have known each other since childhood.（since → 完成时）
- 重点：used to：过去常常（现在不了）
  - used to + 动词原形：过去经常 / 过去是这样，现在不再了：I used to live in Shanghai.
  - 否定 didn't use to；疑问 Did you use to …?
  - 别和 be used to doing（习惯于）混：I'm used to getting up early.
  - 一句话：used to do 过去常常；be used to doing 习惯于。
  - 常错：I use to live there. → I used to live there.（肯定句是 used）
  - 常错：I used to getting up early.（习惯） → I'm used to getting up early.（习惯于 = be used to doing）
已有题目示例（不要重复，也不要只换几个词）：
  - [o] From now on, I will study every day.
