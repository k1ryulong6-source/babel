# 单元简报：en.1.2 辅音与拼读

单元目标：辅音、辅音组合、重音、连读与弱读；见词能读
讲解课 5 课；题库现有 0 题，目标 60 题（每课约 12 题）。

## 第 1 课（l = 1）：清辅音与浊辅音　题库已有 0 题
情境：听 back 和 bag、coat 和 goat：口型一样，区别只在喉咙振不振动。
新词：woman、through、life、child、work、down、may、after、should、call、world、over
搭配 / 表达：of course、come back、give up
- 重点：清辅音和浊辅音：bag 不是 back
  - 英语辅音大多成对：口型完全一样，区别在声带振不振动。
  - 清（不振动）/p/ /t/ /k/ /f/ /s/ ↔ 浊（振动）/b/ /d/ /ɡ/ /v/ /z/
  - 摸着喉咙读 /s/ 和 /z/：/z/ 能感到“嗡嗡”的振动。
  - 一句话：清浊口型一样，浊音声带振动、前面元音更长。
  - 常错：bag 读成 back → bag：元音拉长，g 要振动（词尾浊辅音）
  - 常错：very 读成 fery → very：上齿咬下唇并振动（/v/ 是浊音）
- 重点：复数和三单的 -s：/s/、/z/、/ɪz/ 三种读法
  - 前面是清辅音（p t k f）→ 读 /s/：books, cups, likes, stops
  - 前面是浊辅音或元音 → 读 /z/：dogs, bags, sees, plays
  - 前面是 s, z, sh, ch, x, ge → 读 /ɪz/：buses, watches, boxes, pages
  - 一句话：清后 /s/，浊后 /z/，咝音后 /ɪz/。
  - 常错：dogs 读成 /dɒɡs/ → dogs /dɒɡz/（浊音后读 /z/）
  - 常错：watches 读成 /wɒtʃs/ → watches /ˈwɒtʃɪz/（ch 后加 /ɪz/）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 听音，选出听到的词。　选项：coat / goat　答案：coat
  - [f] Don't give ___. You can do it!　答案：up
  - [o] Of course you can come back.

## 第 2 课（l = 2）：中国学生的难点辅音　题库已有 0 题
情境：think、thank、three 的 th，very 的 v，west 的 w，right 的 r —— 这一课专门对付中国学生最难的几个辅音。
新词：school、still、try、last、ask、need、too、feel、state、never、become、between
搭配 / 表达：think about、all right、thank you very much
- 重点：th 要伸舌头：think 不是 sink
  - /θ/（清）think, three, thank：舌尖轻轻放在上下齿之间，往外吹气，不振动。
  - /ð/（浊）this, that, the, mother：同样的口型，声带振动。
  - 一句话：th：舌尖放在上下齿之间，清 /θ/ 吹气，浊 /ð/ 振动。
  - 常错：think 读成 sink → think /θɪŋk/（舌尖伸到齿间）
  - 常错：this 读成“贼斯” → this /ðɪs/（浊音 /ð/，舌尖同样在齿间）
- 重点：v 和 w、l 和 r
  - v：上齿轻咬下唇，振动 —— very, van, vest
  - w：双唇收圆向前，不碰牙齿 —— west, way, we
  - l：舌尖顶住上齿龈 —— light, long, play
  - r：舌尖往后卷，不碰任何地方，嘴唇略圆 —— right, wrong, red
  - 一句话：v 牙碰唇，w 不碰；l 舌尖碰，r 不碰。
  - 常错：very 读成 wery → very：上齿咬下唇（）
  - 常错：right 读成 light → right：舌尖卷起，不碰上颚（）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 听音，选出听到的词。　选项：sin / sing　答案：sing
  - [f] I'm thinking ___ my trip.　答案：about
  - [o] All right, I think this is the way.

## 第 3 课（l = 3）：辅音组合与不发音字母　题库已有 0 题
情境：phone 的 ph、write 的 w、know 和 knight 的 k、night 的 gh —— 英语有一批“写了不读”或“两个字母读一个音”的拼写。
新词：high、something、really、most、another、much、family、own、leave、put、old、while
搭配 / 表达：each other、write down、such as
- 重点：不发音的字母：kn、wr、mb、igh
  - kn 的 k 不读：know, knife, knee
  - wr 的 w 不读：write, wrong, wrist
  - mb 的 b 不读：climb, comb, lamb
  - igh 的 gh 不读：high, night, light
  - 还有：listen 的 t、hour / honest 的 h、half 的 l
  - 一句话：kn-、wr-、-mb、-igh、listen、hour：写了不读。
  - 常错：know 读成 /knəʊ/ → know /nəʊ/（k 不读）
  - 常错：listen 读成 /ˈlɪstən/ → listen /ˈlɪsn/（t 不读）
- 重点：辅音连缀和词尾辅音：不要加元音
  - 英语常有几个辅音连在一起：street, spring, desk, text。中间不要插元音。
  - 词尾的 p / t / k 是“收住”的：嘴形做到位就停，不要在后面加“呃”：ship 不是“希普”，desk 不是“戴斯克”。
  - 一句话：辅音之间、辅音之后都不加元音；词尾 p/t/k 做好口型就停。
  - 常错：ship 读成 /ʃɪpə/ → ship /ʃɪp/，双唇闭上就停（词尾 p 不加元音）
  - 常错：street 读成“斯去瑞特” → street /striːt/（str 连在一起）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] phone 中 ph 读？　选项：/p/ / /f/ / /h/ / /v/　答案：/f/
  - [c] city 中 c 读？　选项：/k/ / /s/ / /tʃ/ / /ʃ/　答案：/s/
  - [c] 哪个单词的 ch 读 /tʃ/？　选项：much / school / machine / chef　答案：much

## 第 4 课（l = 4）：音节与单词重音　题库已有 0 题
情境：把 hard、test、school 读对还不够：多音节词读错重音，母语者常常根本听不出是哪个词。
新词：mean、keep、student、why、let、great、same、big、group、begin、seem、country
搭配 / 表达：at least、in fact、pick up
- 重点：单词重音：读错重音比读错元音更难懂
  - 多音节词有一个重读音节：更响、更长、音调更高。其余音节轻、短，元音常弱化成 /ə/。
  - 规律（不是绝对）：双音节名词、形容词多重前：STU·dent, TA·ble, HAP·py；双音节动词多重后：be·GIN, de·CIDE。
  - -tion / -sion / -ic 结尾：重音在它前一个音节：in·for·MA·tion, e·co·NOM·ic。
  - 同一个词名动不同：a PRE·sent 礼物 / to pre·SENT 展示；a RE·cord / to re·CORD。
  - 一句话：重读音节又响又长；其余音节轻读成 /ə/。
  - 常错：com-PU-ter 读成 COM-pu-ter → com·PU·ter（）
  - 常错：in-for-ma-TION → in·for·MA·tion（-tion 本身不重读）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] computer 有几个音节？　选项：2 / 3 / 4 / 5　答案：3
  - [c] 听音，选出重音位置正确的描述。　选项：重音在第一个音节 / 重音在第二个音节　答案：重音在第二个音节
  - [f] You need ___ least eight hours of sleep.　答案：at

## 第 5 课（l = 5）：连读、弱读与节奏　题库已有 0 题
情境：注意 want to 读成 “wanna”、pick it up 连成一串。听不懂英语对话，很多时候是因为只认识“一个一个念”的词。
新词：help、talk、where、turn、problem、every、start、hand、might、show、part、against
搭配 / 表达：want to、go out、a little
- 重点：连读和弱读：英语是“一串一串”说的
  - 连读：辅音结尾 + 元音开头的词连在一起：pick it up → /pɪkɪtʌp/，an apple → /ənæpl/，turn off → /tɜːnɒf/。
  - 弱读：不重读的功能词变轻、变短：to → /tə/，and → /ən/，can → /kən/，of → /əv/，for → /fə/。
  - 口语常见合音：want to → wanna，going to → gonna，got to → gotta（听得懂即可，写作不用）。
  - 一句话：实词重读，功能词轻读；辅音 + 元音就连起来。
  - 常错：I want to go 每个词一样重 → I WANT to GO —— to 轻读 /tə/（）
  - 常错：pick / it / up 分开读 → /pɪkɪtʌp/ 连成一串（）
- 重点：can 和 can't：靠重音分辨
  - can 在句中通常弱读 /kən/，重音落在后面的动词上：I can GO.
  - can't 永远重读，元音饱满（美式 /kænt/，英式 /kɑːnt/），结尾的 t 常听不清：I CAN'T go.
  - 一句话：can 轻、can't 重。
  - 常错：I CAN go（重读 can） → I can GO（can 轻读）（否则听起来像 can't）
已有题目示例（不要重复，也不要只换几个词）：
  - [c] 句子中通常重读的是？　选项：the / and / 名词和动词 / to　答案：名词和动词
  - [c] I am 的缩略形式是？　选项：I'm / Im' / I'am / Iam　答案：I'm
  - [f] Let's go ___ for dinner tonight.　答案：out
