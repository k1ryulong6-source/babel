# 课纲数据格式

`index.json` 是总目录：语言 → 阶段（学期）→ 单元。

- 写好内容的单元有 `file`，指向 `curriculum/<语言>/<阶段>-<单元>.json`。
- 还没写的单元有 `todo`（说明该写什么），可能还有 `plan`（预定的课时标题）。
- 补内容时，照下面的格式写好单元文件，把 index 里该单元的 `todo` 换成 `file`，再运行 `python3 tools/update_manifest.py`。
- 已经存在的课时 id 不要改，学习进度按 id 记录。

## 单元文件

```jsonc
{
  "id": "en.1.3", "title": "句子的骨架", "goal": "……",
  "lessons": [{
    "id": "en.1.3.1", "title": "词性：单词的八种身份",
    "words": ["say", "people", {"w": "noun", "p": "/naʊn/", "s": [["n.", "名词"]], "x": [["\"Book\" is a noun.", "book 是名词。"]]}],
    "grammar": [{"ref": "b_pos"}, {"title": "……", "points": ["……"], "examples": [["英文", "中文"]]}],
    "special": [{"w": "be good at", "t": "固定搭配", "s": [["", "擅长"]], "x": [["She is good at math.", "她擅长数学。"]]}],
    "exercises": [
      {"t": "c", "q": "She ___ a nurse.", "o": ["am", "is", "are", "be"], "a": 1, "e": "解析"},
      {"t": "c", "say": "ship", "q": "听到的是哪个词？", "o": ["ship", "sheep"], "a": 0, "e": "……"},
      {"t": "f", "q": "They ___ (be) from Osaka.", "a": ["are"], "e": "……"},
      {"t": "o", "a": "This is my brother.", "zh": "这是我哥哥。"},
      {"t": "o", "p": ["私は", "毎朝", "新聞を", "読む"], "a": "私は毎朝新聞を読む", "zh": "我每天早上看报纸。"}
    ]
  }],
  "test": {"n": 20, "extra": [ /* 和 exercises 同格式，只在单元测验里出 */ ]}
}
```

### words：新词

- 字符串：引用词库里已有的词条（英语 `data/words.json`、日语 `ja/words.json`、西语 `es/words.json`），自带释义、例句、录音。
- 对象：词库里没有的词，写完整词条。
  - `w`：词。
  - `p`：音标；日语写读音；西语名词写性别 `m` / `f` / `mf`。
  - `s`：`[[词性, 释义]]`。
  - `x`：`[[例句, 译文]]`。
  - 可选：`t` 类型标签、`c` 常用搭配、`n` 备注。

### grammar：语法点

- `{"ref": id}`：引用现有课程。
  - 英语：零基础语法 `b_*`、进阶主题（`tense` 等）、TOEIC 语法 `t_*`。
  - 西语：语法课 `ser-estar` 等。
  - 日语：文型（写文型本身，如 `〜をもって`）。
  - 被引用课程自带的题目会自动并入本课练习。
- 自写：`title` + `points`（要点，可含简单 HTML）+ `examples`。

### special：特殊词汇

- 英语：固定搭配、短语动词。
- 西语：常用表达。
- 日语：惯用句、四字熟语、拟声拟态语、敬语、谚语。

格式同 `words`（字符串引用词库，对象自写）。学完后和新词一样进入间隔复习。

### exercises：练习

| `t` | 题型 | 字段 |
|---|---|---|
| `c` | 选择题 | `q` 题干，`o` 选项，`a` 正确选项下标；可加 `say`：先朗读再作答（听力、辨音） |
| `f` | 填空题 | `a` 是可接受答案的列表，不分大小写，忽略首尾标点 |
| `o` | 连词成句 | `a` 是正确句子，按空格切分后打乱；日语、或需要自定切分时给 `p`（片段数组），`zh` 是中文提示 |

所有题型都可以带 `e`（解析）。

### 单元测验 test

- 从本单元所有课时的练习里抽题，再加上 `extra` 里的测验专用题，共 `n` 题。
- 正确率达到及格线（默认 80%）才算通过；没通过就进入回炉，复习薄弱的课时后重新测验。

## v2 课时：一步一屏的引导式教学（steps）

课时里写 `steps`（代替 words / grammar / special / exercises）就用新的播放器：一屏一个步骤，先讲再练，学一点马上检查一点。进度按步骤保存，退出后回来接着上。

```jsonc
{"id": "es.1.2.1", "title": "自我介绍：llamarse", "steps": [
  {"t": "intro", "title": "开学第一天", "lines": [["A", "Hola, me llamo Ana.", "你好，我叫安娜。"]], "note": "这一课学会……"},
  {"t": "teach", "title": "“我叫……”：Me llamo", "body": ["讲解段落，可含简单 HTML"], "ex": [["Me llamo Lucía.", "我叫露西娅。"]],
   "tip": "中国学生常错的地方", "tipTitle": "（可选，默认“中国学生常错”）", "check": {"t": "c", "q": "……", "o": ["…"], "a": 0}},
  {"t": "word", "w": "nombre", "hint": "记忆提示（可选；不写就显示词库里的注意事项）"},
  {"t": "word", "w": "¿Cómo te llamas?", "sp": true, "s": [["", "你叫什么名字？"]], "x": ["例句", "译文"], "tt": "常用表达"},
  {"t": "speak", "text": "Hola, me llamo Ana.", "zh": "……", "focus": "跟读时注意什么"},
  {"t": "c", "q": "……", "o": ["…"], "a": 0, "e": "解析"},
  {"t": "sum", "points": ["本课要点"]}
]}
```

- `word`：引用词库里的词只写 `w`；词库里没有的写 `s`（释义）和 `x`（[例句, 译文]）；`sp: true` 表示特殊词汇（搭配、表达、惯用句）。
- 连续几张词卡后自动插入一轮「回忆」小测；`teach` 的 `check` 在讲解后单独一屏出题。
- 练习题（`c` / `f` / `o`，格式同上）答错的会在小结前再做一遍，并进错题本。
- 最后一步必须是 `sum`。单元测验照常从本单元所有课时的题目（含 check）里抽。

## v4 新增：重点、整句题、写作

```jsonc
{"t": "key", "title": "英语句子必须有谓语动词",
 "what": ["是什么（段落，可含简单 HTML）"], "why": ["为什么这样用"], "zh": ["和中文比一比"],
 "ex": [["I am busy.", "我很忙。"], ["……由易到难……", "……"]],
 "err": [["I busy.", "I am busy.", "为什么错"]],
 "sum": "一句话记住",
 "drill": [{"t": "c", ...}, {"t": "f", ...}, {"t": "tr", ...}]}
{"t": "tr", "zh": "我们很忙。", "a": ["We are busy.", "We're busy."], "e": "解析"}
{"t": "dict", "a": "I run in the park every night."}
{"t": "write", "prompt": "用 3–4 句话介绍你的一天", "hint": "可选提示", "focus": "给 AI 批改看的本单元重点", "model": "参考范文"}
```

- `key`（重点）：播放器拆成几屏 —— 是什么 / 为什么 → 和中文比 + 例句由易到难 → 常犯的错 + 一句话记住 → `drill` 逐题练，答错的会再出，直到做对。学完进「重点笔记」，按 1、2、4、7、15… 天间隔复习（每日计划里的「重点复习」）。每课 1–3 个重点，每个重点至少 3 道练习。
- 下一课开头自动出「课前回顾」：上一课每个重点的最后一道练习。
- `tr`（中译外）：`a` 写几种可接受的说法；判分忽略大小写、标点、英语缩写。说法不同但意思对时，学习者可以自己判对。
- `dict`（听写）：播放 `a` 的录音，写下整句。日语暂时没有录音，先不要用。
- `write`（写作）：有 AI 时自动批改（改错、原因、改好的版本），没有 AI 时显示参考范文。写的内容存在计划记录里。
- 课时按「屏」计时（约 1.1 分钟一屏）：每日计划里时间不够就学到第 N 屏，下次接着上；时间多就连着上下一课。

## 单元阅读（每个单元最后一课）

每个单元最后加一课「单元阅读」：一篇只用本单元及以前学过的词和重点写成的短文，加 4–6 道理解题。
这一课标 `"story": true`，单元的 `n`（课时数）要把它算进去。

```json
{"id": "en.1.3.6", "title": "单元阅读：Mr. Chen's Day", "story": true, "steps": [
  {"t": "read", "title": "Mr. Chen's Day", "note": "读前提示",
   "lines": [["Mr. Chen works for a small company.", "陈先生在一家小公司工作。"], ["", ""], ["…", "…"]]},
  {"t": "c", "rdq": true, "q": "What does Mr. Chen do every morning?", "o": ["…", "…", "…"], "a": 0, "e": "解析"},
  {"t": "tr", "rdq": true, "zh": "他的老板给他很多工作。", "a": ["His boss gives him a lot of work."]},
  {"t": "sum", "points": ["本文用到的重点……"]}
]}
```

- `read.lines`：一句一行 `[原文, 中文]`，`["", ""]` 表示分段。每句都会预录音，可整篇朗读；译文默认隐藏。
- 理解题带 `"rdq": true`，答题时可以展开回看短文。
- 篇幅：英语 90–200 词，西语 70–150 词，日语 300–400 字，难度随单元递增。
