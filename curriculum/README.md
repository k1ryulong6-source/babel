# 课纲数据格式

`index.json` 是总目录：语言 → 阶段（学期）→ 单元。

- 写好内容的单元有 `file`，指向 `curriculum/<语言>/<阶段>-<单元>.json`。
- 还没写的单元有 `todo`（说明该写什么），可能还有 `plan`（预定的课时标题）。
- 补内容时，照下面的格式写好单元文件，把 index 里该单元的 `todo` 换成 `file`，再运行 `python3 tools/update_manifest.py`。
- 已经存在的课时 id 不要改，学习进度按 id 记录。

## 单元文件

```jsonc
{
  "id": "en.1.3", "title": "句子的骨架", "goal": "……",
  "lessons": [{
    "id": "en.1.3.1", "title": "词性：单词的八种身份",
    "words": ["say", "people", {"w": "noun", "p": "/naʊn/", "s": [["n.", "名词"]], "x": [["\"Book\" is a noun.", "book 是名词。"]]}],
    "grammar": [{"ref": "b_pos"}, {"title": "……", "points": ["……"], "examples": [["英文", "中文"]]}],
    "special": [{"w": "be good at", "t": "固定搭配", "s": [["", "擅长"]], "x": [["She is good at math.", "她擅长数学。"]]}],
    "exercises": [
      {"t": "c", "q": "She ___ a nurse.", "o": ["am", "is", "are", "be"], "a": 1, "e": "解析"},
      {"t": "c", "say": "ship", "q": "听到的是哪个词？", "o": ["ship", "sheep"], "a": 0, "e": "……"},
      {"t": "f", "q": "They ___ (be) from Osaka.", "a": ["are"], "e": "……"},
      {"t": "o", "a": "This is my brother.", "zh": "这是我哥哥。"},
      {"t": "o", "p": ["私は", "毎朝", "新聞を", "読む"], "a": "私は毎朝新聞を読む", "zh": "我每天早上看报纸。"}
    ]
  }],
  "test": {"n": 20, "extra": [ /* 和 exercises 同格式，只在单元测验里出 */ ]}
}
```

### words：新词

- 字符串：引用词库里已有的词条（英语 `data/words.json`、日语 `ja/words.json`、西语 `es/words.json`），自带释义、例句、录音。
- 对象：词库里没有的词，写完整词条。
  - `w`：词。
  - `p`：音标；日语写读音；西语名词写性别 `m` / `f` / `mf`。
  - `s`：`[[词性, 释义]]`。
  - `x`：`[[例句, 译文]]`。
  - 可选：`t` 类型标签、`c` 常用搭配、`n` 备注。

### grammar：语法点

- `{"ref": id}`：引用现有课程。
  - 英语：零基础语法 `b_*`、进阶主题（`tense` 等）、TOEIC 语法 `t_*`。
  - 西语：语法课 `ser-estar` 等。
  - 日语：文型（写文型本身，如 `〜をもって`）。
  - 被引用课程自带的题目会自动并入本课练习。
- 自写：`title` + `points`（要点，可含简单 HTML）+ `examples`。

### special：特殊词汇

- 英语：固定搭配、短语动词。
- 西语：常用表达。
- 日语：惯用句、四字熟语、拟声拟态语、敬语、谚语。

格式同 `words`（字符串引用词库，对象自写）。学完后和新词一样进入间隔复习。

### exercises：练习

| `t` | 题型 | 字段 |
|---|---|---|
| `c` | 选择题 | `q` 题干，`o` 选项，`a` 正确选项下标；可加 `say`：先朗读再作答（听力、辨音） |
| `f` | 填空题 | `a` 是可接受答案的列表，不分大小写，忽略首尾标点 |
| `o` | 连词成句 | `a` 是正确句子，按空格切分后打乱；日语、或需要自定切分时给 `p`（片段数组），`zh` 是中文提示 |

所有题型都可以带 `e`（解析）。

### 单元测验 test

- 从本单元所有课时的练习里抽题，再加上 `extra` 里的测验专用题，共 `n` 题。
- 正确率达到及格线（默认 80%）才算通过；没通过就进入回炉，复习薄弱的课时后重新测验。
